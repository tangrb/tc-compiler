# TC-Compiler

#### 介绍
TC-Compiler 是一个用纯 C99 实现的自定义伪汇编语言 TC 的编译器/虚拟机项目，包含直接执行引擎（TC-VM）和预留的提前编译框架（TC-AOT），支持词法分析、语法分析、静态类型检查及逐条指令执行。
