### Phase 0 — 实现契约设计（不改码；A1/A2 前置）

| 任务 | 内容 | 产出 |
| ---- | ---- | ---- |
| P0-1 | 读 §3.5/§3.8.2 定 **A1 元素布局契约**：元素 `i` 的抽象位区间 `[i×w, (i+1)×w)`（w=sizeof_bits(T)），头部为 usize 数学值；确定元素存取改为显式位串读写（不再经宿主 `memcpy` 低字节） | A1 实现口径（位偏移公式 + 大小端无关读写例程） |
| P0-2 | 读 §10.4 定 **A2 输出算法**：选型（位模式精确十进制生成 + roundTiesToEven；`%e` 两位指数；`%g` 指数阈值与去尾零；特殊值 INF/NAN/±0 符号）；float32 输出不经 float64 舍入（双舍入定理仅对 int→float 成立，float32→decimal 需直接精确） | A2 算法伪码 + §10.4 全表测试矩阵 |
| P0-3 | 核对 **B2 指针语义**：§3.10.8 步长为 `sizeof_bits(T)` 位粒度，偏移类型严格 `usize`；确认 VM 与 AOT 两路径当前差异 | B2 修改点清单 |

**Phase 0 定稿契约（2026-08-30）**：

**A1 端序契约（依据 §3.5 / §3.8.2）**
- 抽象布局：`memblock = [usize 头部 | elem0 | … | elem_{count-1}]`，元素紧密排列；元素/字段的抽象位串按 §3.5「MSB→LSB 数值位权」定义，与宿主字节序无关。
- 存储约定：**元素/字段字节区间内一律按固定 LE（低字节在前）序列化**（显式位组装，不依赖宿主字节序；LE 主机与既有 memcpy 行为逐字节一致，BE 主机得到相同抽象值）；读/写两端同一约定 → 任意字节序主机得到相同数值结果。
- 改动面：元素读写（`tc_memblock_exec.c`）、字段读写（`tc_struct_exec.c`）、头部 usize、AOT runtime shim（`tc_aot_rt.c`）、const 构造/字段折叠（`tc_const_eval.c`、`tc_aot_codegen.c`、`tc_aot_emit_rhs.c`）共用同一 LE 约定；`bool` 规范化（0x00/0x01）保持；结构体/memblock 字段为不透明字节块整块复制。
- 验收：`test_endianness.c` 原始字节断言（头部/元素/字段 LE 布局，与宿主无关）+ VM/AOT 差分 + 既有值语义测试不回退。

**A2 输出契约（依据 §10.4 / §10.5）**
- 特殊值：`inf`/`-inf`/`nan`（`%E`/`%G` 大写）；NaN 不因符号位输出 `-`，`+` 标志产生 `+inf`/`+nan`；NaN payload 不外泄。
- 有限值：从 binary32/64 位模式**精确**十进制化（大整数法：mantissa × 2^exp → 十进制数字串 + 十进制指数），roundTiesToEven 到目标精度；**float32 直接精确，不借道 float64**。
- `%f`：定点，默认 6 位小数；`%e`/`%E`：1 位整数 + 默认 6 位小数 + 指数（`±` 至少两位）；`%g`/`%G`：默认 6 位有效数字（`.0` 按 1），`e < -4 || e >= p` 用科学形，否则定点，去尾零（`#` 除外）；负零保留符号。
- 组装顺序（§10.5）：数字文本 → 符号/进制前缀 → width 填充（`-` 右补空格、`0` 在符号后零填、`inf/nan` 的 `0` 按空格）；`%08.3f` → `0003.142`。
- 验收：§10.4/§10.5 全表黄金输出（含舍入边界、指数边界、float32/float64 分离、`%g` 阈值、`#` 备用形式、宽度 65535 上限）；删除宿主 `snprintf` 浮点委托点。

**B2 指针契约（依据 §3.10.8）**
- `ptr_add`/`ptr_sub` 的 `offset` 操作数**必须为 `usize`**（非负、位粒度步长 `n × sizeof_bits(T)`）；`isize` 偏移为非法（静态类型检查拒绝）。
- 改动面：`tc_ptr_exec.c` 去掉 `TC_ISIZE` 回退（`109-113`），偏移严格 `TC_USIZE` 求值；分析器已有 usize 类型要求则核对；AOT emit 同步。

## 4. 风险与注意事项

1. **A2（printf 自实现）是最大风险项**：§10.4 的舍入/指数/去尾零规则组合多，必须按全表黄金用例逐行对照；先 P3-1 核心再 P3-2/3/4 逐层，每层独立绿。
2. **A1 端序改动牵动 VM+AOT+const 三路径**：凡元素/字段存取点都要同步（grep `memcpy` + `bits` 全量盘点）；LE 主机只能靠位模式构造断言验证「端序无关」，需把测试写成**抽象位串断言**而非宿主字节断言。
3. **B1 下溢判定**：tininess-after-rounding 与 fenv 路径的差分是唯一验收手段，no-fenv 构建必须与 fenv 构建输出一致（含 `%e` 指数边界）。
4. **C1 附录 B 变更**：85→86 必须与 `check_doc_counts.py` 数字源同一提交（0.0.42 已确立的防作弊规则），禁止单独改脚本。
5. **远程 CI**：tc-0.0.42 未在 workflow 触发分支列表，Phase 7 前必须补上，否则无法用远程矩阵验证。
6. 所有改动遵循 AGENTS.md：先 `rg` 定位、改后最小回归（`--filter`）、动 `TcRhsKind`/错误码后跑 `check_rhs_coverage.py`/`check_doc_counts.py`。
