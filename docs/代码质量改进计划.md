## P4-01：parser 拆分（已完成）

**动机**：单文件兼具缩进引擎、16 种 RHS 与 AST 释放，内聚度低。

**交付布局**：

| 文件 | 职责 | 约行数 |
|------|------|--------|
| `tc_parser.c` | `tc_parse_source_to_program`、缩进 / if、语句入口 | ~1000 |
| `tc_parser_rhs.c` + `.h` | `tc_parse_rhs` / `tc_parse_const_rhs` 及辅助 | ~940 |
| `tc_parser_free.c` + `.h` | `tc_rhs_free` / `tc_statement_free` / program 生命周期 | ~175 |
| `tc_parser_internal.h` | parser 内部共享声明 | — |

已更新：`CMakeLists.txt`、`check_source_naming.py`、知识图谱 / features 路由。

---

## P4-02：semantics 拆分（已完成）

**动机**：整数 / 浮点 / 位运算混在同一大文件，不利独立演进。

**交付布局**：

| 文件 | 职责 | 约行数 |
|------|------|--------|
| `tc_semantics.c` + `.h` | 共享工具、字面量、哨兵、对外入口 | ~420 |
| `tc_sem_int.c` + `.h` | 整数算术 / cast | ~600 |
| `tc_sem_fp.c` + `.h` | 浮点算术 / 比较 / cast（strict/ieee/wrap） | ~590 |
| `tc_sem_bitwise.c` + `.h` | 位运算 / 移位 | ~225 |

工具函数保留在 `tc_semantics.c`（非再抽 `tc_sem_util`），子模块经公共头链接。

---

## P4-03：analyzer 拆分（已完成）

**动机**：Pass1 / Pass2 / 数据流 / REPL 生命周期耦合，单文件过长。

**交付布局**：

| 文件 | 职责 | 约行数 |
|------|------|--------|
| `tc_analyzer.c` + `.h` | `tc_analyze`、`TcTypedProgram` 生命周期 | ~90 |
| `tc_analyzer_pass1.c` + `.h` | Pass1 符号收集 / slot | ~145 |
| `tc_analyzer_pass2.c` + `.h` | Pass2 类型检查、标签、goto 合法性 | ~1100 |

| `tc_analyzer_repl.c` + `.h` | REPL 增量分析 | ~155 |
| `tc_analyzer_internal.h` | 分析器内部共享 | — |
