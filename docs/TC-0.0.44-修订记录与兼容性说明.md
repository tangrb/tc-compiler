> **适用规范**：[TC 语言标准设计说明书-0.0.44.md](./TC语言标准设计说明书-0.0.44.md)
> **本文件性质**：**资料性**。承载 0.0.44 的修订历史与相对 0.0.42 的兼容性差异，**不构成一致性要求**；规范性内容以语言标准正文为准。
> **维护约定**：语言标准正文只保留**现在时**的规范条款（§1.3「单一事实源」）；历史、差异与迁移信息一律记录在本文件。

## 1. 兼容性与版本差异（0.0.42 → 0.0.44）

本版为**勘误与口径收敛版**：不新增语言能力，也不改变任何程序构造的书写方式；条款编号、附录 A 产生式与错误码集合（仍 86 码）保持稳定。下表按影响面分类，供实现迁移与跨版本一致性判定使用。每条对应的修订细节见文末「变更记录」。

### 1.1 接受集变化（实现需相应调整）

| 变化 | 条目 | 方向 |
| ---- | ---- | ---- |
| 指针 `cast`（`cast(ptr<U> → ptr<T>)`）不再要求**所指类型等宽**，只要求 `T`/`U` 均为 `void` 以外的完整类型（指针值恒等宽，§3.10.5） | D14 | **放宽** |
| 指针指令（`ptr_load`/`ptr_store`/`ptr_add`/`ptr_sub`/`ptr_size`/`ptr_eq`/`ptr_ne`/`ptr_lt`/`ptr_le`/`ptr_gt`/`ptr_ge`/`memcopy_unsafe`）的指针操作数接受任意 `operand`，含结构体字段读取 `a.p` 与 `nullptr`；`ptr_address` 仍限裸名/限定名 | D12 | **放宽** |
| `memblock` 的 `N` / `count:` 接受带 `u`/`U` 后缀的整数字面量（与 §2.3.1 的无符号上下文规则一致） | D5 | **澄清为合法** |
| `bitcast(ptr ↔ 浮点)`：0.0.42 按 §6.6.6 字面为合法，本版明确**非法**（`TC_CE_TYPE_MISMATCH`） | D10 | **收紧** |
| `add(usize, ptr_size(int32, nullptr), 1u)` 等**两级调用**：D15 曾放宽，D18 撤回 | D15 → D18 | **净无变化**（恢复 §1.1「单层表达式」） |

### 1.2 诊断变化（错误码集合不变，仍 86 码）

| 变化 | 条目 |
| ---- | ---- |
| `var` 缺初始化器：`TC_CE_VAR_MISSING_INIT` 阶段由 SEM 改为 **SYN**（结构类语法阶段诊断） | D4 |
| 指针指令出现在 `const_rhs`：由「部分位置不给码／`TC_CE_CONSTANT_EXPRESSION`」统一为**语法拒绝** `TC_CE_SYNTAX`（7 处） | D13 |
| 结构体名冲突：重复定义 → `TC_CE_DUPLICATE_STRUCT`；与函数名／值绑定名冲突 → `TC_CE_FUNCTION_NAME_CONFLICT`；与导入名冲突 → `TC_CE_IMPORT_NAME_CONFLICT`（原均无码） | D7 |
| 同一作用域内重复声明同名 `var`/`let` → `TC_CE_DUPLICATE_DEFINITION`（原触发条件仅"与形参同名"） | D16 |
| 实参形态与形参类型不匹配（如向标量形参传构造器）→ `TC_CE_TYPE_MISMATCH`（原无码） | D17 |
| `memblock` 的 `N` / `count:` 来源不合法或数学值 < 1 → `TC_CE_CONSTANT_EXPRESSION`（原无码） | D5 |
| 前导零十进制字面量 → 语法拒绝 `TC_CE_SYNTAX`（原未说明归属） | D17 |
| **首个规范诊断的选取顺序**：由「实现自行规定」改为§11 的**规范性四步规则**（阶段优先 → 同阶段按源序位置 → 同位置专用码优先 → 条款内既有顺序优先） | D19 |

### 1.3 语义澄清（不改变接受集与诊断码，仅消除歧义）

| 澄清 | 条目 |
| ---- | ---- |
| 实现定义行为**穷尽为 4 条**：越界指针解引用、`memcopy_unsafe` 越界拷贝、`nullptr` 抽象位模式、经等宽 `bitcast` 观测的抽象槽编码 | D8 |
| `ptr_load` 结果类型为 `bool` 时按「`0x00` → `false`，其它字节 → `true`」规范化（含经指针别名读到非规范字节的路径） | D16 |
| `static var` 初始化器可引用当前源序中更早已成功初始化的 `static var`；在程序准备阶段按运行时语义求值，失败报 `TC_RE_*` | D16 |
| §1.3「语法阶段拒绝」两档口径：语法拒绝（`TC_CE_SYNTAX` ＋ 2 个专用码）与**结构类语法阶段诊断**（4 个专用码），共 **6 个**语法阶段专用码 | D3、D4 |
| 常量操作数集合：字段读取与 `.count` 可嵌套；`ptr_size` 是调用型 RHS，**只能整条作 `const_rhs`** | D9、D15 → D18 |
| 枚举补全：四种转换形式（§6.6.1）、`ptr_eq`/`ptr_ne`（§1.1.1）、RHS／操作数总表与附录 A 产生式对齐、模块类型名作用域（§9.1）、位运算适用类型含 `isize`/`usize` | D11、D14、D17 |

### 1.4 迁移提示

- **收紧项**：只需 `bitcast(ptr ↔ 浮点)` 一处——若实现曾按 0.0.42 接受，改为报 `TC_CE_TYPE_MISMATCH`（D10）。
- **放宽项**：`cast(ptr<int32>, p_uint8)` 这类**所指类型不同但均完整**的指针重标记必须接受（D14）；字段读取作指针操作数必须接受（D12）。
- **诊断项**：`TC_CE_VAR_MISSING_INIT` 必须落在语法阶段（D4）；`const_rhs` 中的指针指令必须报 `TC_CE_SYNTAX`（D13）；首诊断须按 §11 四步规则可复现（D19）。
- **无需改动**：错误码总数与各码语义均未增删；所有程序构造的书写方式与条款编号不变。
- **编辑性收敛（D22～D24，无迁移影响）**：重复定义合并（规则改为「单点权威 ＋ `§` 引注」）、修订历史移出规范正文、实现细节清理。实现方只需按新术语（「结构类语法阶段诊断」）与新的引用位置定位条款，**行为与诊断均不变**。
