## 1. 审查口径

### 1.1 审查范围

本报告覆盖 TC 0.0.35 的全部设计—实现规范追踪，涵盖以下新增领域：

| 领域 | 0.0.31 基线 | 0.0.35 新增 |
| ---- | ---------- | ---------- |
| 模块系统 | 单文件 | `#program`/`#lib`、`import`、`public`/`private`、`Self`、DAG 依赖图 |
| 函数 | 无 | `func`/`funcall`/`return`、命名实参、按值只读形参、无环调用图 |
| 类型 | 标量（12 种） | 增加 `ptr<T>`、`memblock<T,N>`、`struct`、`isize`/`usize`、`void` |
| 运算 | 算术/位/比较/逻辑/cast/bitcast | 增加全部 `ptr_*`、`memblock_*`、`memcopy_unsafe` 指令 |
| 编译管线 | 6 阶段 | 13 确定性阶段（含 4/6 阶段内部子阶段） |
| 错误码 | 41+1 | 70+（含函数、模块、memblock、struct、ptr 专用诊断） |
| REPL | 包含 | 已删除 |
| 程序入口 | 顶层语句 | `#program` 顶层语句 |

### 1.2 判定规则

| 状态 | 含义 |
| ---- | ---- |
| 通过 | 规范要求已映射到实现，且有自动化行为证据 |
| 未实现 | 设计已定但实现待完成 |
| 不适用 | 不属于 0.0.35 规范或本次发布边界 |

### 1.3 证据层次

各项审查需要三层证据：

1. **设计层面**：规范条款 → 设计文档映射
2. **实现位置**：设计文档 → 源码模块/函数
3. **测试覆盖**：源码 → 测试用例 + 门禁通过
