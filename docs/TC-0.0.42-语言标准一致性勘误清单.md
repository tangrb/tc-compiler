## 1. 分类与勾选口径

### 1.1 三类落点

| 类别 | 含义 | 判定依据 |
| ---- | ---- | -------- |
| **甲 · 建议修改附录 A** | 附录 A 为孤例，正文多处以另一种写法自洽 | 改动落在 A.2 / A.3 的产生式或注释 |
| **乙 · 修改正文** | 附录 A 为权威（§1.3 明文），或问题纯属正文内部不一致 | 改动落在 §1–§11、附录 B |
| **丙 · 需产品决策** | 两侧都有理由，结论会改变**合法程序集**或**诊断阶段** | 先登记决议，再决定落到甲或乙 |

### 1.2 优先级

- **P0**：不改则合法程序集或诊断归属无法判定（实现之间会分歧）。14 项。
- **P1**：交叉引用错误、错误码缺口、条款互斥但合法集明确。22 项。
- **P2**：措辞、完备性、条款对称性等不影响判定的问题。8 项。

### 1.3 勾选与回填约定

- 每条以 `- [ ]` 开头，处置完成改为 `- [x]`，并在行尾追加 `→ 处置：<提交号 / 决议编号>`。
- 丙类**不可直接勾选为完成**：须先在 §5.2 登记决议，再跟踪其"落地条目"。
- 甲类条件项（A-05～A-08）与乙类部分条目**依赖丙类决议**，勾选前先确认关联决议已登记。
