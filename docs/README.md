## 过程记录

本目录**不再保留**过程性文档（符合性审计报告、整改进度台账、分析报告、修复计划等），以保持设计/规范文档的单一事实源。

> 历史过程文档（0.0.44 符合性审计报告、0.0.44 整改进度台账、0.0.41 分析报告／修复计划、0.0.42 遗留问题清零计划、0.0.42 规范文本）已从仓库移除；需要时用发布标签恢复，例如 `git show v0.0.44:docs/TC-0.0.44-语言标准符合性审计报告.md`。
>
> 设计/规范文档**不得**引用过程性记录（分层检查：`scripts/sync/check_doc_layering.py`，其过程文档名标记仍生效）。
