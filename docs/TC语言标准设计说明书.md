## 1. 概述

### 1.1 语言定位

TC 是一门伪汇编语言：语法接近高级语言的赋值表达式，执行模型保留汇编式的 **逐条语句** 顺序执行。每条语句至多包含 **一个** 运算或转换调用，**不支持** 表达式嵌套。

本文档定义：

- **8 种** 固定宽度整数类型（`int8`～`uint64`）
- **1 种** 布尔类型（`bool`，取值为 `true`/`false`）
- **7 类** 算术运算指令：
  - 双目运算（5 类）：`add`、`sub`、`mul`、`div`、`mod`
  - 单目运算（2 类）：`abs`（取绝对值）、`neg`（取负数）
- **4 类** 位运算指令：`and`、`or`、`xor`（按位逻辑）、`not`（按位取反）
- **2 类** 移位运算指令：`shl`（左移）、`shr`（右移）
- **6 类** 比较运算指令：`eq`、`ne`、`lt`、`le`、`gt`、`ge`
- **3 类** 逻辑运算指令：`and`、`or`、`not`（布尔逻辑，与整数位运算共享关键字，由类型参数区分）
- **1 类** 类型转换指令：`cast`
- **3 条** 标准 I/O 语句：`write`、`writeln`、`read`
  - `write`/`writeln` 支持格式化输出（8 种格式化符号，含 `%t`）
- **控制流语句**：`if-then-else`（Pascal 风格，缩进敏感，以 `end` 结束）
- 算术回绕模式关键字 **`wrap`**（用于 `add`/`sub`/`mul`/`neg`/`shl`）
- 类型转换截断模式关键字 **`truncate`**（用于 `cast`）

### 1.2 设计原则

| 原则           | 说明                                                         |
| -------------- | ------------------------------------------------------------ |
| 声明与赋值分离 | 首次定义使用 `var`，后续修改省略 `var`                       |
| 常量与变量分离 | 不可变常量使用 `let` 定义，须在编译期初始化                  |
| 显式类型标注   | 变量/常量定义须声明具体类型                                  |
| 运算函数化     | 算术以 `op(<类型> [, wrap], 操作数...)` 形式调用；比较/逻辑以 `op(<类型>, 操作数...)` 形式调用 |
| 类型参数首位   | 运算与转换的类型均作为 **第一个参数** 显式给出               |
| 默认严格溢出   | 有符号 `add`/`sub`/`mul`/`neg` 与 `cast` 默认检测溢出并报错；回绕或截断须显式传入对应关键字 |
| 同类型运算     | 同一运算的操作数须为相同类型                                 |
| 显式类型转换   | 跨类型须通过 `cast` 完成，禁止隐式转换                       |
| 逐条执行       | 每条语句独立执行，无隐式表达式嵌套求值                       |
| 字面量类型显式 | 无后缀字面量为有符号整数；`u`/`U` 后缀字面量为无符号整数；`true`/`false` 为布尔字面量 |
| I/O 格式化     | `write`/`writeln` 支持格式化符号，单符号单操作数             |
| 缩进强制       | 块结构由缩进界定，`if`/`else`/`end` 缩进必须一致，块内语句缩进必须多一级 |

### 1.3 设计哲学

TC 的设计遵循以下核心理念：

| 理念             | 说明                                                         |
| ---------------- | ------------------------------------------------------------ |
| **显式优于隐式** | 类型转换、溢出处理、符号性、块结束（`end`）均须显式标注，杜绝隐式歧义 |
| **安全优先**     | 默认检测溢出和转换错误，将运行时可预测性置于性能之上         |
| **教学友好**     | 伪汇编风格让底层概念（位宽、符号、溢出、截断）直观可见；缩进强制培养结构化编程习惯 |
| **渐进扩展**     | 当前聚焦整数与布尔子集，为未来浮点、复合类型预留清晰的设计空间 |

### 1.4 完整示例

以下是一个完整的 TC 程序，展示语言的核心能力（含控制流）：

```text
; ============================================================
; 全局变量与常量
; ============================================================
var a: int32 = 10
var b: int32 = 20
let SCALE: int32 = 1000
let DEBUG: bool = true

; ============================================================
; 常量表达式
; ============================================================
let BASE: int32 = 1000
let MULTIPLIER: int32 = 3
let SCALED_BASE: int32 = mul(int32, BASE, MULTIPLIER)   ; 3000
let THRESHOLD: int32 = 100
let IS_VALID: bool = gt(int32, SCALED_BASE, THRESHOLD)   ; true
let FLAG: bool = true
let FLAG_AS_INT: int32 = cast(int32, FLAG)               ; 1

; ============================================================
; 算术运算
; ============================================================
var sum: int32 = add(int32, a, b)           ; 30
var diff: int32 = sub(int32, a, b)          ; -10
var prod: int32 = mul(int32, a, b)          ; 200
var quot: int32 = div(int32, b, a)          ; 2
var rem: int32 = mod(int32, b, a)           ; 0

; ============================================================
; 比较与逻辑
; ============================================================
var is_equal: bool = eq(int32, a, b)        ; false
var is_less: bool = lt(int32, a, b)         ; true
var is_less_or_equal: bool = or(bool, is_equal, is_less)  ; true

; ============================================================
; if-else 控制流（缩进敏感，以 end 结束）
; ============================================================
var max: int32
if gt(int32, a, b) then
    max = a
else
    max = b
end
writeln(int32, %d, max)                     ; 20

; ============================================================
; 回绕与截断
; ============================================================
var max_i8: int8 = 127
var one: int8 = 1
var wrapped: int8 = add(int8, wrap, max_i8, one)  ; -128
var big: int32 = 1000
var result_i8: int8 = cast(int8, truncate, big)  ; -24

; ============================================================
; 布尔与整数互转
; ============================================================
var flag: bool = cast(bool, a)              ; true
var as_int: int32 = cast(int32, is_equal)   ; 0

; ============================================================
; I/O
; ============================================================
write(int32, %d, sum)                      ; "30"
writeln(int32, %d, SCALED_BASE)            ; "3000\n"
writeln(bool, %t, is_less)                 ; "true\n"
```

## 2. 词法结构

本章定义 TC 语言的基本词法单元。完整的 EBNF 定义见附录 A。

### 2.1 字符集与 Token

TC 源文件由以下字符构成：

- **字母**：`A`–`Z`、`a`–`z`、`_`
- **数字**：`0`–`9`
- **符号**：`+`、`-`、`*`、`/`、`%`、`=`、`:`、`,`、`(`、`)`、`;`、`_`
- **空白**：空格、制表符（`\t`）、换行符（`\n`、`\r\n`、`\r`）

源文件编码为 **UTF-8**，但语言关键字和标识符仅限于 ASCII 字符集。

### 2.2 标识符

- 由字母、数字与 `_` 组成，**必须以字母或 `_` 开头**。
- **区分大小写**：`a` 与 `A` 为不同变量。
- 合法：`a`、`count`、`_tmp1`、`my_var`
- 非法：`1a`、`-x`（`-` 非标识符字符）

### 2.3 整数字面量

#### 2.3.1 后缀与符号性

TC 字面量通过后缀区分符号性：

| 后缀      | 符号性 | 示例                   |
| --------- | ------ | ---------------------- |
| 无后缀    | 有符号 | `42`、`-128`、`0xFF`   |
| `u` / `U` | 无符号 | `42u`、`255u`、`0xFFu` |

**关键规则**：
- 无后缀字面量视为有符号整数，可用于有符号类型上下文；若用于无符号上下文，须满足范围约束
- `u` 后缀字面量视为无符号整数，**仅可用于无符号类型上下文**；用于有符号上下文触发 **字面量类型错误**
- 负号 `-` **仅可与无后缀字面量**组合；`-42u` 为非法

#### 2.3.2 进制

TC 支持四种进制字面量：

| 进制           | 前缀        | 数字字符集                | 示例                      |
| -------------- | ----------- | ------------------------- | ------------------------- |
| 十进制（默认） | —           | `0`–`9`                   | `0`、`255`、`-128`、`42u` |
| 十六进制       | `0x` / `0X` | `0`–`9`、`a`–`f`、`A`–`F` | `0xFF`、`0x1Au`、`-0x80`  |
| 二进制         | `0b` / `0B` | `0`、`1`                  | `0b1010`、`0b11111111u`   |
| 八进制         | `0o` / `0O` | `0`–`7`                   | `0o377`、`-0o100`         |

- 前缀中的 `0` 是必需的前导，**不区分大小写**
- 前缀与数字之间 **不可有空白**
- 后缀紧跟数字部分，前缀与后缀之间 **不可有空白**

#### 2.3.3 数字分隔符

为增强长数字的可读性，允许在下述位置插入单个下划线 `_`：

- 十进制：数字之间（首数字之后，末数字之前）
- 十六进制：`0x`/`0X` 与末数字之间
- 二进制：`0b`/`0B` 与末数字之间
- 八进制：`0o`/`0O` 与末数字之间

示例：

```text
1_000_000           → 1000000
0xFFFF_0000u        → 4294901760
0b1010_0011u        → 163
-0x7F_FF            → -32767
```

**约束**：不可连续两个 `_`，不可在字面量首尾放置 `_`，不可在前缀内部插入 `_`（如 `0x_FF` 非法）。

#### 2.3.4 前导零

- 十进制字面量 **不允许前导零**（`007` **非法**，应写作 `7`）
- 单个 `0` 是合法的十进制零，不视为前导零特例
- 八进制须显式使用 `0o` 前缀

#### 2.3.5 字面量的词法上限

- 字面量的**数值**不得超过 `uint64` 范围：`0 ≤ N ≤ 18446744073709551615`
- 字面量超出此范围 → **字面量范围错误**

#### 2.3.6 负号与减法运算符的关系

`-` 前缀仅出现在无后缀整数字面量中，**不作为独立的一元运算符**。若需变量间的减法，使用 `sub` 指令。

#### 2.3.7 词法分析器匹配策略

词法分析器采用 **最长匹配** 策略：
1. 扫描 `0` 时，检查后续字符是否为 `x`/`X`/`b`/`B`/`o`/`O`，转入对应进制（十六进制、二进制或八进制）
2. 数字部分扫描完成后，检查后续字符是否为 `u`/`U`，归约为带后缀字面量
3. 否则归约为无后缀字面量

### 2.4 布尔字面量

| 字面量  | 值   | 类型   |
| ------- | ---- | ------ |
| `true`  | 真   | `bool` |
| `false` | 假   | `bool` |

**约束**：
- `true` 和 `false` 为保留关键字，不可用作标识符
- 布尔字面量不区分大小写（均为小写）
- 布尔字面量 **仅可用于** `bool` 类型上下文

```text
var flag: bool = true
var done: bool = false
var err: int32 = true      ; 字面量类型错误
```

### 2.5 浮点字面量（预留）

> **扩展预留**：未来版本将支持浮点字面量，语法形式为：
> - 十进制浮点：`3.14`、`-0.5`、`1.0`
> - 科学计数法：`1.2e5`、`-3.14E-2`
> - 后缀：`f`（`float32`）、无后缀（`float64`）
>
> 当前版本中，包含 `.` 或 `e`/`E` 的数字序列为 **词法错误**。

### 2.6 字符与字符串字面量（预留）

> **扩展预留**：未来版本将支持：
> - 字符字面量：`'a'`、`'\n'`、`'\x41'`
> - 字符串字面量：`"hello"`、`"world\n"`
>
> 当前版本中，单引号或双引号包裹的内容为 **词法错误**。

### 2.7 注释

- 行注释以 `;` 开始，延续至行尾
- 示例：`var a: int32 = 10    ; 定义 32 位整数`

### 2.8 关键字

以下 token 为保留关键字，不可用作标识符：

```text
var  let  bool  true  false
int8  uint8  int16  uint16  int32  uint32  int64  uint64
add  sub  mul  div  mod  abs  neg
eq  ne  lt  le  gt  ge
and  or  not           ; and/or/not 支持 bool 逻辑与整数按位重载
xor                    ; 仅整数位运算，不支持 bool
shl  shr
cast  wrap  truncate
write  writeln  read
if  then  else  end
```

> **扩展预留**：以下关键字为未来功能保留：`goto`、`loop`、`func`、`return`、`float32`、`float64`、`string`、`array`、`struct`、`ptr`。

### 2.9 语句与行结构

- 每条语句独占一行
- **空行**、**仅含空白符的行**、**仅含行注释**的行均合法，不产生语句
- 语句末尾 `;` **可选**；`;` 同时起语句结束和注释标记作用，其后内容均视为注释

## 3. 类型系统

### 3.1 类型分类

TC 的类型系统设计为可扩展的分类体系。当前支持 **整数类型** 和 **布尔类型**，未来将逐步引入其他类别：

| 类别            | 当前支持           | 未来预留                 | 说明                   |
| --------------- | ------------------ | ------------------------ | ---------------------- |
| **整数类型**    | ✅ `int8`～`uint64` | `int128`、`uint128`      | 固定宽度二进制补码整数 |
| **布尔类型**    | ✅ `bool`           | —                        | 逻辑真/假              |
| **浮点类型**    | —                  | `float32`、`float64`     | IEEE 754 浮点数        |
| **字符/字符串** | —                  | `char`、`string`         | Unicode 字符与字符串   |
| **复合类型**    | —                  | `array`、`struct`、`ptr` | 聚合与间接类型         |
| **单位类型**    | —                  | `void`                   | 无值（用于函数返回）   |

> **实现注记**：编译器内部 `TcIntType` 枚举将 `TC_BOOL` 与 `int8`～`uint64` 共用同一枚举类型（便于统一位宽与 I/O 处理），但 `tc_type_is_integer()` 仅对 `int8`～`uint64` 返回真；概念上 bool 仍属独立类别，与上表一致。

### 3.2 整数类型

| 类型     | 位宽 | 符号   | 最小值                     | 最大值                     |
| -------- | ---- | ------ | -------------------------- | -------------------------- |
| `int8`   | 8    | 有符号 | −128                       | 127                        |
| `uint8`  | 8    | 无符号 | 0                          | 255                        |
| `int16`  | 16   | 有符号 | −32,768                    | 32,767                     |
| `uint16` | 16   | 无符号 | 0                          | 65,535                     |
| `int32`  | 32   | 有符号 | −2,147,483,648             | 2,147,483,647              |
| `uint32` | 32   | 无符号 | 0                          | 4,294,967,295              |
| `int64`  | 64   | 有符号 | −9,223,372,036,854,775,808 | 9,223,372,036,854,775,807  |
| `uint64` | 64   | 无符号 | 0                          | 18,446,744,073,709,551,615 |

类型命名规则：`<符号前缀><位宽>`，其中符号前缀为 `int`（有符号）或 `uint`（无符号），位宽为 `8`/`16`/`32`/`64`。

### 3.3 布尔类型

`bool` 类型表示逻辑真值，取值为 `true` 或 `false`。

**内部表示**：
- 在运行时，`bool` 值以字节存储。
- `false` 的表示为其存储单元的所有位均为 `0`。
- `true` 的表示为任何非零的位模式（建议实现统一为 `1`）。
- 但 **不可** 将 `bool` 直接解释为整数（须通过 `cast` 显式转换）。

**类型性质**：
- 比较运算和逻辑运算的结果类型为 `bool`。
- `bool` 变量可被赋值、读取、输出。
- `bool` 变量默认值为 **未定义**（同其他类型）。

```text
var flag: bool           ; 声明但未初始化
flag = true              ; 合法
var done: bool = false   ; 声明并初始化
```

### 3.4 类型性质

**有符号类型（`int8`～`int64`）**

- 采用 **二进制补码** 表示
- `add`/`sub`/`mul`/`neg` 默认 **严格模式**：结果超出范围 → **整数溢出错误**
- 显式 `wrap` 模式：按模 `2^n` 回绕，不报错
- `shl` 默认严格模式：左移结果超出范围 → **整数溢出错误**；`wrap` 模式截断高位

**无符号类型（`uint8`～`uint64`）**

- 仅表示非负整数
- 算术结果超出最大值时 **模 `2^n` 回绕**，不报错
- `div`/`mod` 结果恒为非负
- `shl` 默认严格模式（仍可检测值溢出，例如 `uint8(255) << 1` 超过 255 时报错），`wrap` 模式截断高位

**布尔类型**

- 仅表示逻辑真值
- 比较运算和逻辑运算返回 `bool`
- 不参与算术运算（须显式 `cast`）

**运行时值模型**

TC 中每个变量的值由 **n 位位模式**（`n` 为类型位宽）与 **类型解释** 共同构成：

- 整数内部以 n 位无符号位模式存储；有符号类型按 **二进制补码** 解释，无符号类型按非负整数解释
- `bool` 内部以字节存储，语义上仅区分零和非零
- `wrap` 算术回绕与 `cast(..., truncate, ...)` 均在此位模式上操作
- 有符号 `wrap` 下的 `add`/`sub`/`mul`/`neg` 与同位宽无符号默认回绕 **位模式一致**

### 3.5 字面量与类型的关系

整数字面量的符号性由后缀决定，数值须满足上下文类型的约束：

```text
; 有符号字面量（无后缀）——可用于有符号类型
var a: int8 = 127           ; 合法
var b: int8 = 128           ; 字面量范围错误
var c: int32 = -100         ; 合法

; 有符号字面量用于无符号类型——需满足范围
var e: uint8 = 255          ; 合法
var f: uint8 = 256          ; 字面量范围错误
var g: uint8 = -1           ; 字面量范围错误

; 无符号字面量（u 后缀）——仅可用于无符号类型
var h: uint8 = 255u         ; 合法
var j: int32 = 42u          ; 字面量类型错误

; 布尔字面量——仅可用于 bool 类型
var flag: bool = true       ; 合法
var err: int32 = true       ; 字面量类型错误
```

#### 字面量检查规则

**整数字面量**：
1. 解析字面量数值 `N`（`0 ≤ N ≤ 18446744073709551615`）
2. 若带负号（仅无后缀字面量允许），取 `−N`（`N=0` 时 `−0 = 0`）
3. 根据后缀确定符号性：
   - 无后缀 → 有符号
   - `u`/`U` 后缀 → 无符号
4. 检查上下文类型：
   - 有符号类型：仅允许无后缀字面量，值在范围内
   - 无符号类型：允许无后缀（≥0）或 `u` 后缀字面量，值在范围内
5. 不满足则报错

| 上下文类型 | 允许的字面量形式        | 可接受数值范围                                          |
| ---------- | ----------------------- | ------------------------------------------------------- |
| `int8`     | 无后缀                  | −128 ～ 127                                             |
| `uint8`    | 无后缀（≥0）或 `u` 后缀 | 0 ～ 255                                                |
| `int16`    | 无后缀                  | −32,768 ～ 32,767                                       |
| `uint16`   | 无后缀（≥0）或 `u` 后缀 | 0 ～ 65,535                                             |
| `int32`    | 无后缀                  | −2,147,483,648 ～ 2,147,483,647                         |
| `uint32`   | 无后缀（≥0）或 `u` 后缀 | 0 ～ 4,294,967,295                                      |
| `int64`    | 无后缀                  | −9,223,372,036,854,775,808 ～ 9,223,372,036,854,775,807 |
| `uint64`   | 无后缀（≥0）或 `u` 后缀 | 0 ～ 18,446,744,073,709,551,615                         |

**布尔字面量**：
- `true` 仅可用于 `bool` 类型上下文
- `false` 仅可用于 `bool` 类型上下文
- 用于非 `bool` 类型 → **字面量类型错误**

**`wrap`/`truncate` 不绕过字面量检查**：即使运算或转换使用回绕/截断模式，字面量仍须在上下文类型范围内通过静态检查。

### 3.6 类型转换的通用框架

TC 的所有类型转换统一使用 `cast` 指令。转换行为由以下维度决定：

| 维度         | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| **源类型**   | 当前值的类型                                                 |
| **目标类型** | 要转换到的类型                                               |
| **模式**     | 严格模式（默认，无关键字）：数值可表示性检查；截断模式（`truncate`）：按位截断/扩展/重解释 |

当前实现的转换规则针对整数类型和布尔类型。未来扩展浮点、复合类型时，将复用此框架，补充各类型特定的转换语义。

### 3.7 作用域

TC 采用 **全局作用域** 与 **块级作用域** 相结合的设计：

- **全局作用域**：文件顶层（即不在任何 `if`/`else` 块内部）定义的 `var` 变量和 `let` 常量属于全局作用域。全局标识符在整个文件中可见（需遵循源序可见性），生命周期贯穿程序运行始终。
- **块级作用域**：每个 `if` 语句（从 `if` 行到对应的 `end` 行）构成一个独立的块级作用域。`then` 与 `else` 各自为互斥子作用域：两侧局部标识符互不可见，但允许分别定义同名局部变量。块内定义的 `var` / `let` 在 `end` 之后不可访问。嵌套块支持内层屏蔽外层同名标识符（建议避免）。
- **源序可见性**：变量/常量在**定义语句执行之后**才可供后续语句引用。定义自身的 RHS **不可**引用自身，亦不可引用尚未定义的标识符。
- **变量生命周期**：
  - 全局变量：程序启动时分配存储，程序终止时销毁。
  - 局部变量（块内）：进入块时分配存储（编译期静态分配或运行时栈分配），退出块（遇到 `end`）时销毁。若局部变量未初始化即被读取，仍触发编译警告，值为未定义。

> **扩展预留**：未来引入函数时，将进一步增加函数级局部作用域。

### 3.8 变量生命周期

| 阶段             | 行为                                                    |
| ---------------- | ------------------------------------------------------- |
| 静态分析         | 解析所有 `var`/`let` 定义，建立符号表（含块级作用域）   |
| `var` 语句执行   | 若有 RHS，计算并写入；若无 RHS，保持 **未初始化**       |
| 读取未初始化变量 | **编译警告**，值为 **未定义**（implementation-defined） |
| `let` 语句执行   | 常量值在编译期确定；运行时仅将编译期结果写入变量槽，不生成运行时算术指令 |
| 赋值语句执行     | 更新对应存储位置                                        |
| `read` 语句执行  | 从 stdin 读入值并写入目标变量，视为 **初始化**          |
| 进入 `if` 块执行 | 块内局部变量分配存储（若已在该路径上定义）              |
| 退出 `if` 块执行 | 遇到对应 `end` 时，块内局部变量销毁                     |
| 程序终止         | 所有变量值失效                                          |

# 第二部分：语句与表达式

## 4. 程序结构与语句

### 4.1 程序构成

TC 源文件由若干 **行** 组成，每行至多一条语句。程序执行的入口为文件的第一条非空、非注释语句，按顺序执行至文件末尾；遇到 `if` 语句时按 §4.7 的条件分支规则选择执行路径。

**语句种类**：变量定义（`var`）、常量定义（`let`）、赋值、I/O（`write`/`writeln`/`read`）、条件分支（`if`-`then`-`else`-`end`）。

**程序结构约束**：
- 源文件由若干行组成；每行至多一条语句
- 空行、纯注释行均合法，不产生语句
- 语句末尾 `;` 可选；`;` 同时起语句结束和注释标记作用
- `if` 块内语句须满足 §4.7.2 的缩进规则

### 4.2 变量定义（`var`）

使用 `var` 声明变量。RHS **可选**：

- **有 RHS**：声明并初始化变量
- **无 RHS**：声明变量，其值初始为 **未定义**

同一作用域内不可重复定义同名变量（作用域包括全局、`if` 块，以及 `then`/`else` 各自的互斥子块，见 §3.7、§4.7.5）。跨类型赋值须先 `cast`。

```text
var a: int32 = 10           ; 声明并初始化
var b: int32                ; 声明但未初始化
var c: int32 = add(int32, a, 20)  ; 合法（a 已初始化）
var d: int8 = cast(int8, truncate, a)
var flag: bool = true       ; 布尔变量
```

> **作用域补充**：若 `var` 出现在 `if` / `else` 缩进块内部，则该变量具有**块级局部作用域**，仅在本块（从定义处到对应的 `end`）内可见。块外任何对该变量的引用均为“未定义标识符错误”。

### 4.3 常量定义（`let`）

使用 `let` 声明 **不可变常量**：

- RHS **必须** 提供
- RHS 须为 **编译期常量表达式**（见下文定义）
- 常量在编译期求值，不生成**运行时算术指令**。程序中 `let` 语句仍占一行位置（执行时直接将编译期求值结果写入变量槽）
- 常量 **不可** 作为赋值语句的左值
- 常量名不可与变量名冲突

#### 编译期常量表达式

`let` 的 RHS 可包含以下任一形式：

**原子表达式**：
- 整数字面量（`42`、`-128`、`0xFFu`）
- 布尔字面量（`true`、`false`）
- 已定义的 `let` 常量引用（`PI`、`MASK`）

**复合表达式**（操作数须为常量表达式）：
- 算术运算：`add`/`sub`/`mul`/`div`/`mod`/`abs`/`neg`（**禁止 `wrap`**）
- 位运算：`and`/`or`/`xor`/`not`（按位）、`shl`/`shr`（移位）。其中 `shl` 隐含严格模式（溢出即报错），**禁止 `wrap`**；`shr` 无溢出风险。
- 比较运算：`eq`/`ne`/`lt`/`le`/`gt`/`ge`
- 逻辑运算：`and`/`or`/`not`（布尔）
- 类型转换：`cast`（**仅限无损转换**：加宽、等宽符号转换、`bool ↔ int`；**禁止 `truncate`**）

**约束**：
- 常量表达式**不可** 引用任何 `var` 变量
- 常量表达式**不可** 引用自身或形成循环依赖
- 常量表达式**不可** 使用 `wrap` 或 `truncate` 关键字
- 有符号常量算术运算或 `shl` 的溢出，在编译期视为 **常量溢出错误** 并终止编译
- 常量表达式中 `div`/`mod` 的除数为 0，视为 **常量除零错误** 并终止编译
- 常量移位表达式中，若移位计数 `k >= n`（类型位宽），`shl` 视为常量溢出错误，`shr` 结果为 `0`

#### 示例

```text
; 基础常量
let PI: int32 = 31415
let MASK: uint32 = 0xFFFF_0000u
let DEBUG: bool = true

; 编译期算术
let ZERO: int32 = sub(int32, 10, 10)          ; 0
let OFFSET: int32 = add(int32, PI, 1000)      ; 32415
let SCALE: int32 = div(int32, 1000, 2)        ; 500

; 编译期比较与逻辑
let IS_POSITIVE: bool = gt(int32, PI, 0)      ; true
let IS_LARGE: bool = gt(int32, PI, 100000)    ; false
let RESULT: bool = and(bool, IS_POSITIVE, not(bool, IS_LARGE))  ; true

; 编译期位运算
let HIGH_BITS: uint8 = 0b1111_0000u
let LOW_BITS: uint8 = 0b0000_1111u
let COMBINED: uint8 = or(uint8, HIGH_BITS, LOW_BITS)   ; 0xFF
let FLIPPED: uint8 = not(uint8, HIGH_BITS)             ; 0x0F
let SHIFTED: uint8 = shr(uint8, HIGH_BITS, 4)          ; 0x0F

; 编译期无损转换
let FLAG_INT: int32 = cast(int32, DEBUG)      ; 1
let FLAG_U8: uint8 = cast(uint8, DEBUG)       ; 1
let PI_U32: uint32 = cast(uint32, PI)         ; 31415

; 常量引用链
let DOUBLE_PI: int32 = mul(int32, PI, 2)      ; 62830
let TRIPLE_PI: int32 = add(int32, DOUBLE_PI, PI)  ; 94245

; ========== 错误示例 ==========
; let ERR1: int32 = add(int32, a, 10)        ; 错误：a 是 var 变量
; let ERR2: int32 = add(int32, PI, 1)        ; 如果 PI 尚未定义 → 未定义错误
; let ERR3: int32 = add(int32, X, X)         ; 错误：X 引用自身
; let ERR4: int8 = abs(int8, -128)           ; 错误：常量溢出（INT8_MIN 不可取绝对值）
; let ERR5: int8 = cast(int8, truncate, 1000) ; 错误：truncate 不允许
; let ERR6: int8 = add(int8, wrap, 127, 1)   ; 错误：wrap 不允许
; let ERR7: int8 = cast(int8, 1000)          ; 错误：常量转换溢出（缩窄）
; let ERR8: uint8 = shl(uint8, 1, 8)         ; 错误：常量溢出（1<<8=256 > 255）
; let ERR9: uint8 = shl(uint8, wrap, 1, 8)   ; 错误：let 禁止 wrap
```

> **作用域补充**：同 `var`，`let` 若定义在块内，其作用域限定于当前 `if` 块（到 `end` 为止）。常量在编译期求值，但可见性仍受块级作用域约束。

### 4.4 赋值语句

对已定义变量重新赋值时 **省略** `var`。右侧结果类型须与变量已声明类型 **完全一致**。

```text
var c: int32 = add(int32, a, b)
c = mul(int32, a, b)        ; 合法
c = cast(int32, d)          ; 跨类型须先 cast

var flag: bool = false
flag = true                 ; 合法
flag = lt(int32, a, b)      ; 合法
flag = and(bool, flag, true) ; 合法
```

**约束**：
- 赋值左侧不可为 `let` 定义的常量。
- 左侧变量可以是当前未初始化的变量，赋值操作会将其初始化（即视为获得初值，后续读取不再触发“未初始化变量”警告）。

### 4.5 右值表达式（RHS）

| 产生式               | 结果类型           | 说明                          |
| -------------------- | ------------------ | ----------------------------- |
| `integer_literal`    | 由左侧变量类型决定 | 须满足字面量符号性及范围约束  |
| `bool_literal`       | `bool`             | `true` 或 `false`             |
| `binary_arith_expr`  | 第一参数类型       | 五种双目算术运算              |
| `unary_arith_expr`   | 第一参数类型       | 两种单目算术运算              |
| `bitwise_expr`       | 第一参数类型       | 按位 `and`/`or`/`xor`（双目） |
| `unary_bitwise_expr` | 第一参数类型       | 按位 `not`（单目）            |
| `shift_expr`         | 第一参数类型       | `shl`/`shr` 移位运算          |
| `compare_expr`       | `bool`             | 六种比较运算                  |
| `binary_logic_expr`  | `bool`             | `and`/`or` 逻辑运算（布尔）   |
| `unary_logic_expr`   | `bool`             | `not` 逻辑运算（布尔）        |
| `cast_expr`          | 第一参数类型       | 类型转换                      |

### 4.6 操作数（Operand）

| 形式              | 约束                                                         |
| ----------------- | ------------------------------------------------------------ |
| *identifier*      | 已定义，且类型与运算类型一致；若为变量且未初始化 → **编译警告** |
| *integer_literal* | 须满足字面量约束                                             |
| *bool_literal*    | 仅用于 `bool` 类型上下文                                     |

**不支持** 嵌套：操作数不可为算术表达式或 `cast` 表达式。复合计算须拆分为多条语句。

### 4.7 控制流语句

TC 提供 **Pascal 风格** 的 `if-then-else` 条件分支语句，采用 **缩进敏感** 的块结构，并以 **`end`** 关键字作为块的强制结束标志。

#### 4.7.1 `if` 语句语法

**强制语法形式**（行结构敏感）：

```text
if <bool_rhs> then
    语句序列
[else
    语句序列]
end
```

- `if`、`then`、`else`、`end` 为保留关键字。
- `<bool_rhs>` 为任何可产生 `bool` 类型结果的右值表达式（参见 §4.5）。
- `then` 关键字必须位于 `if` 行的末尾（其后必须换行），不可在同一行写其他内容（行末注释 `;` 除外）。
- `else` 关键字**必须单独另起一行**，缩进级别必须与对应的 `if` 行**完全一致**。
- `end` 关键字**必须单独另起一行**，缩进级别必须与对应的 `if` 行**完全一致**。`end` 是 `if` 语句的强制结束标志，不可省略。
- **不支持 `else if` 组合关键字**。多分支通过在 `else` 块内嵌套 `if` 实现（见下文）。
- `语句序列` 由零条或多条语句组成，每条语句独占一行，且**必须比所在的 `if` / `else` 行缩进更多**（至少一个缩进级别）。块内允许包含 `var` / `let` 定义、赋值、运算调用、I/O 语句以及嵌套的 `if` 语句。

**重要**：缩进是**强制性的语法规则**。块内所有语句的缩进必须严格大于当前块级缩进。`end` 行的缩进必须等于当前块级缩进。若缩进不符合规则，或缺少 `end`，均视为静态错误，程序不编译。

#### 4.7.2 强制性缩进规则

| 规则编号 | 规则说明                                                     |
| -------- | ------------------------------------------------------------ |
| R1       | 缩进使用**空格**或**制表符**，但同一文件中**必须保持一致**（不可混用）。 |
| R2       | 一个缩进级别定义为固定数量的空格（推荐 **4 个空格**）或一个制表符。具体数量由实现定义，但整个文件必须统一。 |
| R3       | `if`、`else` 和 `end` 行的缩进级别必须**完全一致**，称为**当前块级缩进**。 |
| R4       | 位于 `if` / `else` 之后的语句序列（即块内语句），其每行的缩进必须**严格大于**当前块级缩进（至少多一个级别）。若某行缩进不大于当前块级缩进，且该行不是 `end`，则视为缩进错误。 |
| R5       | `end` 行缩进必须等于当前块级缩进；若缩进不足或过多，均为静态错误。 |
| R6       | 嵌套 `if` 时，内层 `if` 行缩进必须比外层块内语句的缩进再多一级（即外层缩进 + 2 个级别）。内层 `if` 的块内语句再比内层 `if` 多一级，其 `end` 与内层 `if` 对齐。 |

**缩进错误示例**（均触发静态错误）：

```text
if true then
    write(int32, %d, 1)
  write(int32, %d, 2)      ; 缩进不足，块意外结束，错误
end

if true then
    write(int32, %d, 1)
else                          ; else 缩进必须与 if 一致，此处错误
    write(int32, %d, 2)
end

if true then
    write(int32, %d, 1)
else
    write(int32, %d, 2)
  end                         ; end 缩进必须与 if 一致，此处错误
```

#### 4.7.3 多分支写法（链式 `if-else`）

由于 `else if` 不允许写在同一行，链式分支的标准写法为：

```text
if <cond1> then
    语句序列1
else
    if <cond2> then
        语句序列2
    else
        if <cond3> then
            语句序列3
        else
            语句序列4
        end
    end
end
```

每个 `if` 都必须有对应的 `end`，且缩进逐级递增。

#### 4.7.4 执行语义

1. 计算 `<bool_rhs>` 的值。
2. 若为 `true`，执行 `then` 块内的所有语句，执行完后跳过 `else` 部分，直接跳至对应的 `end` 之后继续执行外层后续语句。
3. 若为 `false`，若存在 `else` 分支，则进入 `else` 块执行其内部语句（若 `else` 块内包含 `if`，则按 `if` 规则递归执行）。执行完 `else` 块后，遇到 `end` 继续执行外层后续语句。
4. 若条件为 `false` 且无 `else`，则直接跳至 `end` 之后执行。

#### 4.7.5 作用域与变量定义

- 整个 `if` 语句（从 `if` 行到对应的 `end`）构成一个**块级作用域**。
- `then` 与 `else` 各自构成**互斥子作用域**：同一 `if` 内，`then` 侧定义的局部标识符在 `else` 侧不可见，反之亦然；因执行路径互斥，允许在 `then` 与 `else` 中分别定义**同名**局部变量（静态分析视为不同绑定）。
- 块内允许使用 `var` 和 `let` 定义新的变量/常量；`end` 之后无法访问该 `if` 块内定义的任何局部标识符。
- 嵌套 `if` 时，内层块可访问外层块已定义的变量，除非被内层同名局部变量屏蔽。

```text
var x: int32 = 10
if eq(int32, x, 10) then
    var y: int32 = 20      ; 局部变量 y，仅在 if 块内可见
    writeln(int32, %d, y)
else
    var z: int32 = 30      ; 局部变量 z，仅在 else 块内可见
    writeln(int32, %d, z)
end
; writeln(int32, %d, y)    ; 错误：y 在此处不可见
; writeln(int32, %d, z)    ; 错误：z 在此处不可见
```

#### 4.7.6 与 `let` 常量的交互

`let` 常量可在 `if` 块内定义，作用域同样限于该块。若 `if` 条件中引用 `let` 常量，其值是编译期确定的。

#### 4.7.7 扩展预留

未来版本将增加 `loop`、`goto`、`label` 以及函数定义（`func`/`return`），但当前版本仅提供 `if` 条件分支。

## 5. 算术运算

### 5.1 回绕模式详解（`wrap`）

`add`、`sub`、`mul`（双目）和 `neg`（单目）支持可选的 `wrap` 参数；`div`、`mod`、`abs` **不支持**。

| 调用形式                     | 模式               | 有符号（`int8`～`int64`） | 无符号（`uint8`～`uint64`） |
| ---------------------------- | ------------------ | ------------------------- | --------------------------- |
| `<op>(<T>, 操作数...)`       | 严格模式（默认）   | 超范围 → **整数溢出错误** | 超最大值 → **模 2^n 回绕**  |
| `<op>(<T>, wrap, 操作数...)` | 回绕模式（`wrap`） | 超范围 → **模 2^n 回绕**  | 与三参数形式相同            |

其中 `<op>` ∈ {`add`, `sub`, `mul`, `neg`}；`n` 为 `<T>` 位宽。

**回绕规则**：先按 `<T>` 的位宽与符号性计算算术结果，再取 mod 2^n，将无符号位模式解释为目标类型值。有符号 `wrap` 下的运算与同位宽无符号默认回绕 **位模式一致**。

**严格模式溢出检测**（`add`/`sub`/`mul`/`neg`，有符号类型）：

1. 将操作数按 `<T>` 解码为 int64 有符号值
2. 在 int64 域执行对应运算；若 int64 本身溢出 → **整数溢出错误**
3. 若结果不在 `<T>` 的可表示范围内 → **整数溢出错误**
4. 将结果编码为 `<T>` 的 n 位位模式

**等效位级定义**：
- **`add`**：两个正数之和为负数，或两个负数之和为正数 → 溢出
- **`sub`**：正数减负数得负数，或负数减正数得正数 → 溢出
- **`mul`**：乘积符号与数学整数运算不一致，或绝对值超出目标类型范围 → 溢出
- **`neg`**：操作数为 `INT_MIN` → 溢出

**约束**：
- `wrap` 可用于：`add`、`sub`、`mul`、`neg`
- `div`/`mod` 使用 `wrap` → **关键字错误**
- `abs` 使用 `wrap` → **关键字错误**
- `cast` 使用 `wrap` → **关键字错误**

```text
var a: int8 = 127
var b: int8 = 1
var c: int8 = add(int8, a, b)               ; 整数溢出错误
var d: int8 = add(int8, wrap, a, b)         ; d = -128
```

### 5.2 整数有符号运算（`int8`～`int64`）

| 指令                  | 语义                                                         |
| --------------------- | ------------------------------------------------------------ |
| `add` / `sub` / `mul` | 和 / 差 / 积；严格模式超范围报错，wrap 回绕                  |
| `div`                 | 商，**向零截断**（同 C 有符号 `/`）；除数为 0 → **除零错误**；商不可表示 → **整数溢出错误** |
| `mod`                 | 余数符号与 **被除数** 相同；除数为 0 → **除零错误**；**注**：`mod` 本身不会因值不可表示而报错，因为余数绝对值小于除数，必在类型范围内（除数为 0 已单独处理）。 |
| `abs`                 | 返回绝对值；`INT_MIN` 时严格模式报错                         |
| `neg`                 | 返回相反数；`INT_MIN` 时严格模式报错，wrap 回绕              |

**严格模式溢出检测**（`div`，有符号类型）：

1. 将操作数按 `<T>` 解码为 int64 有符号值
2. 除数为 0 → **除零错误**
3. 计算向零截断商 \(q\)；若 \(q\) 不在 `<T>` 可表示范围内 → **整数溢出错误**

**特殊情形**（\(b \neq 0\)）：

| 表达式                   | 结果 | 说明                                                        |
| ------------------------ | ---- | ----------------------------------------------------------- |
| `div(T, INT_MIN(T), −1)` | —    | **整数溢出错误**（数学商 \(+2^{n-1}\) 不可在 `<T>` 中表示） |
| `mod(T, INT_MIN(T), −1)` | `0`  | 余数为 0，**不报错**                                        |
| `abs(T, INT_MIN(T))`     | —    | **整数溢出错误**                                            |
| `neg(T, INT_MIN(T))`     | —    | 严格模式时 **整数溢出错误**                                 |

**恒等式**（\(b \neq 0\)，且 `div`/`mul`/`sub` 在严格模式下 **不溢出**）：

`mod(<T>, a, b) == sub(<T>, a, mul(<T>, div(<T>, a, b), b))`

> 当 `a = INT_MIN(T)` 且 `b = -1` 时，`div` 因商不可表示而报错，`mul` 亦会溢出，该恒等式不适用。`mod` 的余数仍为 0。无符号类型下该恒等式对任意非零除数 `b` 恒成立。

```text
var g: int32 = 7
var h: int32 = -3
var i: int32 = div(int32, g, h)    ; i = -2

var j: int32 = -7
var k: int32 = 3
var m: int32 = mod(int32, j, k)    ; m = -1

var n: int32 = -42
var o: int32 = abs(int32, n)       ; o = 42
```

### 5.3 整数无符号运算（`uint8`～`uint64`）

| 指令                  | 语义                                                |
| --------------------- | --------------------------------------------------- |
| `add` / `sub` / `mul` | 和 / 差 / 积；超范围 → 按模 2^n 回绕                |
| `div`                 | 数学整数商；除数为 0 → **除零错误**                 |
| `mod`                 | 余数满足 `0 ≤ 余数 < 除数`；除数为 0 → **除零错误** |
| `abs`                 | 恒等返回                                            |
| `neg`                 | 返回 `0 - 操作数`，按模 2^n 回绕                    |

无符号算术天然采用模 2^n 回绕，其位级结果与有符号 `wrap` 模式下的同宽算术一致。

```text
var a: uint8 = 200
var b: uint8 = 100
var c: uint8 = add(uint8, a, b)    ; c = 44

var h: uint8 = 5
var i: uint8 = 10
var j: uint8 = sub(uint8, h, i)    ; j = 251

var k: uint8 = 1u
var l: uint8 = neg(uint8, k)       ; l = 255
```

### 5.4 算术运算的扩展框架

当前版本已实现 **整数算术** 和 **逻辑运算**，以及下文定义的 **位运算**。未来将逐步扩展：

| 运算类别     | 当前支持                                    | 未来扩展                                                    |
| ------------ | ------------------------------------------- | ----------------------------------------------------------- |
| **整数算术** | ✅ `add`/`sub`/`mul`/`div`/`mod`/`abs`/`neg` | 任意位宽整数                                                |
| **位运算**   | ✅ `and`/`or`/`xor`/`not`/`shl`/`shr`        | —                                                           |
| **比较运算** | ✅ `eq`/`ne`/`lt`/`le`/`gt`/`ge`             | —                                                           |
| **逻辑运算** | ✅ `and`/`or`/`not`（布尔）                  | —                                                           |
| **浮点算术** | —                                           | `fadd`/`fsub`/`fmul`/`fdiv`/`fneg`/`fabs`、`sqrt`、`sin` 等 |

## 6. 位运算

本章定义整数位级操作，包括按位逻辑运算与移位运算。位运算与布尔逻辑运算共享关键字 `and`、`or`、`not`，由**类型参数**区分：当类型参数为整数类型时执行按位操作；当类型参数为 `bool` 时执行逻辑运算（见第 7 章）。`xor` 仅用于整数按位运算，不支持布尔类型。

> **重要约束**：移位运算（`shl`/`shr`）中，**被移位数与移位计数必须为相同类型 `T`**。若需要不同位宽（如将 8 位数左移 16 位），必须先用 `cast` 统一类型。语法上，两个操作数必须与类型参数 `T` 一致。

**设计说明：移位计数不掩码**

TC 对移位计数 `k` 的处理方式与主流语言（如 C/C++、Java、Rust）不同，**不进行掩码**，直接取 `k` 的数学值。选择此语义主要基于以下原因：

- **教学清晰**：避免“计数被截断”这一隐含、非直观的行为，使学习者能直接理解移位的数学本质。
- **确定性**：`k >= n` 时行为明确定义（`shl` 严格模式报溢出，`shr` 得 `0`），无依赖于平台或实现的不确定行为。
- **可验证性**：便于形式化证明和静态分析，因为移位操作与位宽 `n` 的直接关系透明可见。
- **显式编程**：若需要取模移位，程序员可显式使用 `mod` 运算，符合 TC“显式优于隐式”的宗旨。

### 6.1 按位逻辑运算（`and`、`or`、`xor`、`not`）

#### 6.1.1 总览

| 运算  | 名称     | 操作数数量 | 适用类型                     | 语义                             |
| ----- | -------- | ---------- | ---------------------------- | -------------------------------- |
| `and` | 按位与   | 2          | 整数类型（`int8`～`uint64`） | 每位：两操作数均为 1 → 1，否则 0 |
| `or`  | 按位或   | 2          | 整数类型                     | 每位：任一操作数为 1 → 1，否则 0 |
| `xor` | 按位异或 | 2          | 整数类型                     | 每位：两操作数不同 → 1，相同 → 0 |
| `not` | 按位非   | 1          | 整数类型                     | 每位取反                         |

> **`xor` 与 `and`/`or`/`not` 的区别**：`and`/`or`/`not` 由类型参数 `T` 重载——`T` 为整数时执行按位运算，`T` 为 `bool` 时执行逻辑运算（见第 7 章）。`xor` **无** bool 重载，仅接受整数类型参数。

#### 6.1.2 语法形式

```text
var a: int8 = 0b1010_1100      ; -84
var b: int8 = 0b1111_0000      ; -16

var and_res: int8 = and(int8, a, b)   ; 0b1010_0000 -> -96
var or_res:  int8 = or(int8, a, b)    ; 0b1111_1100 -> -4
var xor_res: int8 = xor(int8, a, b)   ; 0b0101_1100 -> 92
var not_res: int8 = not(int8, a)      ; 0b0101_0011 -> 83
```

#### 6.1.3 语义规则

1. 将操作数视为 **无符号位模式**（有符号数按二进制补码解释）。
2. 对每一位执行对应的逻辑操作。
3. 结果按目标类型 `T` 解释（有符号按补码回译，无符号直接取值）。

**溢出**：按位运算结果天然限制在 `T` 的位宽内，**不会溢出**，因此**不支持** `wrap` 或 `truncate` 模式。

**操作数约束**：
- 两操作数必须与类型参数 `T` 一致（整数类型）。
- 若类型参数为 `bool`，则 `and`/`or`/`not` 会视为逻辑运算（参见第 7 章），而 `xor` 不允许 `bool` 类型参数，将触发 **类型错误**。
- 未初始化变量读取触发编译警告（同其他运算）。

### 6.2 移位运算（`shl`、`shr`）

移位运算对操作数类型有严格要求：**被移位数与移位计数必须为相同类型 `T`**。若需要不同位宽（如将 8 位数左移 16 位），必须先用 `cast` 统一类型。

#### 6.2.1 左移（`shl`）

- **适用类型**：整数类型（`int8`～`uint64`）。
- **调用形式**：
  - 严格模式（默认）：`shl(<T>, 被移位数, 移位计数)`
  - 回绕模式：`shl(<T>, wrap, 被移位数, 移位计数)`
- **语义**：
  - 将移位计数解释为无符号整数，取其数学值 `k`。**TC 不对 `k` 进行掩码操作**（例如，对于 `uint8` 类型，计数 `8` 仍视为 `8`，而非 `0`）。
  - 若 `k >= n`（`n` 为 `T` 的位宽）：
    - 严格模式：视为 **整数溢出错误**。
    - 回绕模式：所有位被移出，结果为 `0`。
  - **严格模式**（`k < n`）：
    - 计算数学结果：`result_math = 被移位数 * 2^k`（被移位数按有符号/无符号解释）。
    - 若 `result_math` 超出 `T` 的可表示范围 → **整数溢出错误**。
    - 否则存储结果。
  - **回绕模式**（`k < n`）：
    - 取 `(被移位数 * 2^k)` 的低 `n` 位位模式，按 `T` 解释。**不报错**。
- **特殊边界**：
  - 若被移位数为 `0`，则结果恒为 `0`（严格模式不报错）。
  - 有符号负数左移，严格模式按补码值检测溢出。

```text
var x: int8 = 0b0111_1111   ; 127
var cnt: int8 = 2
var r1: int8 = shl(int8, x, cnt)        ; 127*4=508 -> 溢出错误
var r2: int8 = shl(int8, wrap, x, cnt)  ; 508 mod 256 = 0b1111_1100 -> -4

var y: uint8 = 0b1111_1111u   ; 255
var r3: uint8 = shl(uint8, wrap, y, 4)  ; 255*16 mod 256 = 0b1111_0000 -> 240u
var r4: uint8 = shl(uint8, wrap, y, 8)  ; k=8 >=8 -> 0
```

#### 6.2.2 右移（`shr`）

- **适用类型**：整数类型。
- **调用形式**：`shr(<T>, 被移位数, 移位计数)` —— **无模式关键字**（永不溢出）。
- **语义**：
  - 将移位计数解释为无符号整数，取其数学值 `k`。**TC 不对 `k` 进行掩码操作**。
  - 若 `k >= n`（`n` 为 `T` 的位宽），结果为 `0`（因为所有有效位均被移出，剩余位模式全为 0，无论符号位如何）。
  - **符号性规则**（`k < n` 时）：
    - **有符号类型**（`int*`）：执行 **算术右移**——高位补符号位。
    - **无符号类型**（`uint*`）：执行 **逻辑右移**——高位补 `0`。
- **溢出**：右移只缩小数值，**永不溢出**，因此不支持 `wrap`。

```text
var neg: int8 = 0b1000_0000   ; -128
var r5: int8 = shr(int8, neg, 1)   ; -64 (算术右移)
var r6: int8 = shr(int8, neg, 8)   ; k=8 >=8 -> 0

var pos: uint8 = 0b1000_0000u ; 128
var r7: uint8 = shr(uint8, pos, 1) ; 64 (逻辑右移)
```

#### 6.2.3 移位计数范围检查

- **编译期常量**：若移位计数为常量且 `k >= n`，严格模式下 `shl` 触发常量溢出错误；`shr` 不报错（结果为 `0`）。
- **运行时**：若移位计数变量值为负数（有符号类型），由于其无符号解释为一个极大的正数，可能导致 `k >= n`，按上述规则处理（`shl` 严格模式报溢出，`wrap` 得 `0`；`shr` 得 `0`）。建议程序员确保移位计数非负，或先 `cast` 为无符号类型。

### 6.3 位运算与常量表达式

`let` 常量表达式允许使用位运算，但需遵守以下限制：

- `shl` **禁止使用 `wrap`**（常量表达式必须精确）。
- `and`/`or`/`xor`/`not`/`shr` 可正常使用，所有操作数必须为常量表达式。
- 严格模式 `shl` 溢出视为常量溢出错误。
- 示例：

```text
let MASK: uint8 = 0b1111_0000u
let FLIP: uint8 = not(uint8, MASK)        ; 0b0000_1111
let SHIFTED: uint8 = shr(uint8, MASK, 4)  ; 0b0000_1111
; let ERR: uint8 = shl(uint8, wrap, 1, 8) ; 错误：let 禁止 wrap
; let ERR2: uint8 = shl(uint8, 1, 8)      ; 错误：常量溢出
```

## 7. 比较运算与逻辑运算

### 7.1 比较运算

#### 7.1.1 比较运算总览

所有比较运算：
- 接受 **两个同类型整数操作数**（`int8`～`uint64`）
- 返回 `bool` 类型值
- **不涉及** `wrap` / `truncate` 模式
- **不产生溢出**（比较本身无算术溢出风险）

| 运算 | 名称     | 语义     |
| ---- | -------- | -------- |
| `eq` | 等于     | `a == b` |
| `ne` | 不等于   | `a != b` |
| `lt` | 小于     | `a < b`  |
| `le` | 小于等于 | `a <= b` |
| `gt` | 大于     | `a > b`  |
| `ge` | 大于等于 | `a >= b` |

#### 7.1.2 语法形式

```text
var eq_result: bool = eq(int32, a, b)   ; false
var ne_result: bool = ne(int32, a, b)   ; true
var lt_result: bool = lt(int32, a, b)   ; true
var le_result: bool = le(int32, a, b)   ; true
var gt_result: bool = gt(int32, a, b)   ; false
var ge_result: bool = ge(int32, a, b)   ; false
```

#### 7.1.3 语义规则

**有符号整数比较**（`int8`～`int64`）：
- 按二进制补码解释后的数学值比较
- 负数 < 正数，数值大者大

**无符号整数比较**（`uint8`～`uint64`）：
- 按非负整数值比较

**混合符号性**：
- 比较运算的**类型参数 `T` 决定了操作数的解释方式**
- 两操作数须与 `T` 类型一致
- 若需比较不同符号性的整数，须先 `cast` 统一类型

```text
var signed: int32 = -1
var unsigned: uint32 = 42u
; var cmp: bool = lt(int32, signed, unsigned)   ; 类型错误：unsigned 不是 int32
; var cmp: bool = lt(uint32, signed, unsigned)  ; 类型错误：signed 不是 uint32

var unsigned_as_int32: int32 = cast(int32, unsigned)  ; 42
var cmp: bool = lt(int32, signed, unsigned_as_int32)  ; true（-1 < 42）
```

#### 7.1.4 比较运算的链式调用

由于 TC 不支持表达式嵌套，**链式比较须拆分为多条语句**：

```text
; 判断 a < b < c（不支持直接链式）
var a: int32 = 5
var b: int32 = 10
var c: int32 = 15

var step1: bool = lt(int32, a, b)   ; true
var step2: bool = lt(int32, b, c)   ; true
var result: bool = and(bool, step1, step2)   ; 使用逻辑运算组合
```

#### 7.1.5 操作数规则

比较运算的操作数遵循 §4.6 的通用操作数规则：
- 变量：须已定义且类型与 `T` 一致
- 字面量：须满足 §3.5 的字面量约束
- 读取未初始化变量 → **编译警告**

### 7.2 逻辑运算

#### 7.2.1 逻辑运算总览

所有逻辑运算：
- 接受 **`bool` 类型操作数**
- 返回 `bool` 类型值
- **不涉及** `wrap` / `truncate` 模式
- **不产生溢出**

| 运算  | 名称   | 操作数数量 | 语义                                            |
| ----- | ------ | ---------- | ----------------------------------------------- |
| `and` | 逻辑与 | 2          | 两操作数均为 `true` 时返回 `true`，否则 `false` |
| `or`  | 逻辑或 | 2          | 任一操作数为 `true` 时返回 `true`，否则 `false` |
| `not` | 逻辑非 | 1          | 操作数为 `true` 时返回 `false`，否则 `true`     |

#### 7.2.2 短路求值

**`and` 短路规则**：
- 左操作数为 `false` 时，**不计算** 右操作数，直接返回 `false`
- 左操作数为 `true` 时，计算右操作数并返回其值

**`or` 短路规则**：
- 左操作数为 `true` 时，**不计算** 右操作数，直接返回 `true`
- 左操作数为 `false` 时，计算右操作数并返回其值

**`not` 短路规则**：
- `not` 为单目运算，无短路行为

**短路求值的意义**：
- 右操作数若为未初始化变量，短路时可避免 **未初始化变量警告**
- 与 `if` 条件分支配合时，可在单条语句内安全地组合布尔条件，无需嵌套 `if`

#### 7.2.3 语法形式

```text
; 双目逻辑运算
var and_result: bool = and(bool, a, b)   ; a && b
var or_result: bool = or(bool, a, b)     ; a || b

; 单目逻辑运算
var not_result: bool = not(bool, a)      ; !a
```

#### 7.2.4 操作数约束

- 所有操作数须为 `bool` 类型
- 操作数可为 `bool` 变量、`true`/`false` 字面量、比较运算结果、其他逻辑运算结果
- 读取未初始化 `bool` 变量 → **编译警告**
- 操作数类型为整数 → **类型错误**

```text
var x: int32 = 42
var flag: bool = true
; var err: bool = and(bool, flag, x)   ; 类型错误：x 不是 bool
```

#### 7.2.5 真值表

| `and`   | `true`  | `false` |
| ------- | ------- | ------- |
| `true`  | `true`  | `false` |
| `false` | `false` | `false` |

| `or`    | `true` | `false` |
| ------- | ------ | ------- |
| `true`  | `true` | `true`  |
| `false` | `true` | `false` |

| `not`   | 结果    |
| ------- | ------- |
| `true`  | `false` |
| `false` | `true`  |

## 8. 类型转换

### 8.1 截断模式详解（`truncate`）

`cast` 使用 `truncate` 关键字表示按位截断/扩展/重解释。`wrap` 关键字 **不可用于 cast**。

```text
var big: int32 = 1000
var err: int8 = cast(int8, big)                  ; 转换溢出错误
var trunc: int8 = cast(int8, truncate, big)      ; trunc = -24

var n: int32 = sub(int32, 0, 1)                  ; n = -1
var bits: uint8 = cast(uint8, truncate, n)       ; bits = 255
```

### 8.2 整数严格转换规则（strict）

#### 加宽（目标位宽 > 源位宽）

| 源 → 目标       | 规则                              |
| --------------- | --------------------------------- |
| 有符号 → 有符号 | 符号扩展，数值不变                |
| 无符号 → 无符号 | 零扩展，数值不变                  |
| 有符号 → 无符号 | 源 ≥ 0 则转换；源 < 0 → 错误      |
| 无符号 → 有符号 | 源 ≤ 目标 max 则转换；否则 → 错误 |

#### 等宽（位宽相同，符号性不同）

| 源 → 目标       | 规则                              |
| --------------- | --------------------------------- |
| 有符号 → 无符号 | 源 ≥ 0 则转换；源 < 0 → 错误      |
| 无符号 → 有符号 | 源 ≤ 目标 max 则转换；否则 → 错误 |

#### 缩窄（目标位宽 < 源位宽）

| 源 → 目标       | 规则                                     |
| --------------- | ---------------------------------------- |
| 有符号 → 有符号 | 源在目标范围内则转换；否则 → 错误        |
| 无符号 → 无符号 | 截断低 n 位（mod 2^n），**不报错**       |
| 有符号 → 无符号 | 源 ≥ 0 且 ≤ 目标 max 则转换；否则 → 错误 |
| 无符号 → 有符号 | 源 ≤ 目标 max 则转换；否则 → 错误        |

> 无符号 → 无符号缩窄 **不做** 可表示性检查，等价于截断低 n 位。

#### 同类型

源类型与目标类型相同 → 恒等转换。

### 8.3 整数截断转换规则（`truncate`）

设源位宽 `n`、目标位宽 `m`；先将源操作数表示为 `n` 位整数 `bits`（`0 ≤ bits < 2^n`）。

1. **缩窄或等宽**（`m ≤ n`）：取 `bits mod 2^m`，按目标类型解释
2. **加宽**（`m > n`）：
   - 目标无符号，或源无符号：零扩展至 m 位
   - 源、目标均有符号且 `bits` 第 `n−1` 位为 1：符号扩展至 m 位
   - 其余加宽：零扩展至 m 位

| 场景                        | 严格模式 | 截断模式               |
| --------------------------- | -------- | ---------------------- |
| 有符号缩窄超范围            | 错误     | 截断低 m 位并重解释    |
| 有符号 → 无符号（源为负）   | 错误     | 重解释（如 −1 → 255）  |
| 无符号 → 有符号（源 > max） | 错误     | 重解释（如 200 → −56） |
| 无符号 → 无符号缩窄         | 截断     | 截断（相同）           |
| 严格模式下合法的加宽        | 扩展     | 相同结果               |

**`truncate` 结果的类型解释**：

`truncate` 的结果值为目标类型 `T` 的 n 位位模式按 `T` 的类型规则解释后的值。

```text
var neg: int32 = -1
var bits: uint8 = cast(uint8, truncate, neg)    ; bits = 255
var wrapped: uint8 = add(uint8, bits, 1)        ; wrapped = 0
```

truncate 加宽示例：

```text
var v8:  int8  = -1
var ext1: int16 = cast(int16, truncate, v8)    ; ext1 = -1（符号扩展）
var ext2: uint16 = cast(uint16, truncate, v8)  ; ext2 = 255（零扩展）

var u8:  uint8  = 200
var ext3: int16 = cast(int16, truncate, u8)    ; ext3 = 200（零扩展）
```

### 8.4 `bool` ↔ 整数转换规则

`cast` 指令扩展支持 `bool` 与整数类型之间的转换。

#### `bool` → 整数

| 目标类型     | 规则                                      |
| ------------ | ----------------------------------------- |
| 任意整数类型 | `true` → `1`，`false` → `0`               |
| 模式         | 严格模式和截断模式 **行为相同**（无损失） |

```text
var flag: bool = true
var as_int: int32 = cast(int32, flag)   ; 1
var as_u8: uint8 = cast(uint8, flag)    ; 1u
```

#### 整数 → `bool`

| 源类型       | 规则                                      |
| ------------ | ----------------------------------------- |
| 任意整数类型 | `0` → `false`，非 `0` → `true`            |
| 模式         | 严格模式和截断模式 **行为相同**（无损失） |

```text
var x: int32 = 42
var flag: bool = cast(bool, x)   ; true
var y: int32 = 0
var zero_flag: bool = cast(bool, y)   ; false
```

#### `bool` ↔ `bool`（同类型）

同类型转换：恒等，不报错。

### 8.5 整数转换规则速查

为清晰区分两种模式，分别给出严格模式和截断模式的转换表。

#### 严格模式（strict）

| 源 ↓ / 目标 →         | `int8`～`int64`（有符号）        | `uint8`～`uint64`（无符号）   | `bool`                         |
| --------------------- | -------------------------------- | ----------------------------- | ------------------------------ |
| **`int8`～`int64`**   | 范围内保留/符号扩展；超出 → 错误 | 非负且范围内；否则 → 错误     | `0` → `false`，非 `0` → `true` |
| **`uint8`～`uint64`** | ≤ 目标 max；否则 → 错误          | 同宽/缩窄：截断；加宽：零扩展 | `0` → `false`，非 `0` → `true` |
| **`bool`**            | `true` → `1`，`false` → `0`      | `true` → `1`，`false` → `0`   | 恒等                           |

#### 截断模式（truncate）

截断模式**仅适用于整数 → 整数**转换（目标类型和源类型均为整数类型）。`bool` ↔ 整数互转在截断模式下与严格模式行为相同，但**语法上不允许**使用 `truncate` 关键字（因为 `truncate` 关键字只能用于 `int_type` 目标，见附录 A EBNF）。如需转换，请使用严格模式。

截断模式下，任意整数源 → 任意整数目标，按位模式算法处理，**不报错**。具体规则同 §8.3。

| 源 ↓ / 目标 →         | `int8`～`int64`（有符号） | `uint8`～`uint64`（无符号） |
| --------------------- | ------------------------- | --------------------------- |
| **`int8`～`int64`**   | 按位截断/符号扩展，不报错 | 按位截断/零扩展，不报错     |
| **`uint8`～`uint64`** | 按位截断/零扩展，不报错   | 按位截断/零扩展，不报错     |

> **注意**：`bool` ↔ 整数转换**不能**使用 `truncate` 关键字，因为 `truncate` 仅设计用于整数 → 整数转换。若需转换 `bool` 与整数，请使用严格模式（不加 `truncate`），其行为与截断模式一致（无损失）。

#### 常量转换的额外约束

当 `cast` 用于 `let` 常量表达式的 RHS 时，适用以下额外约束：

| 转换方向            | 严格模式 | 截断模式 |
| ------------------- | -------- | -------- |
| 整数 → 整数（加宽） | ✅ 允许   | ❌ 禁止   |
| 整数 → 整数（等宽） | ✅ 允许   | ❌ 禁止   |
| 整数 → 整数（缩窄） | ❌ 禁止   | ❌ 禁止   |
| `bool` → 整数       | ✅ 允许   | ❌ 禁止   |
| 整数 → `bool`       | ✅ 允许   | ❌ 禁止   |
| `bool` → `bool`     | ✅ 允许   | ❌ 禁止   |

**设计理由**：常量表达式应保持值的精确可计算性。缩窄和 `truncate` 可能损失信息，违背“常量应清晰可读”的原则。如需截断或缩窄，应使用 `var` 在运行时完成。截断模式下禁止 `bool` 转换的原因是 `truncate` 语法仅支持整数目标类型。

### 8.6 类型转换的扩展框架

当前实现了 **整数 ↔ 整数** 和 **整数 ↔ `bool`** 的转换。未来将扩展：

| 转换场景    | 当前支持 | 说明                                 |
| ----------- | -------- | ------------------------------------ |
| 整数 ↔ 整数 | ✅        | 任意位宽组合                         |
| 整数 ↔ 布尔 | ✅        | 整数与 `bool` 互转                   |
| 整数 ↔ 浮点 | —        | `cast(float32, int32_val)`           |
| 浮点 ↔ 浮点 | —        | 精度转换（如 `float32` ↔ `float64`） |
| 指针 ↔ 整数 | —        | 地址与整数互转                       |
| 复合类型    | —        | 结构体转换、数组重解释               |

## 9. 标准 I/O

### 9.1 `write` — 不换行输出

**形式一：无格式输出**

| 项目       | 说明                                                         |
| ---------- | ------------------------------------------------------------ |
| 语法       | `write(int32, x)`、`write(uint8, 42u)`、`write(bool, flag)`  |
| 功能       | 将操作数的值按类型解释，以十进制/文本写入 stdout，**不换行** |
| 操作数规则 | 变量（须已定义）或字面量                                     |
| 类型约束   | 变量类型与 `type` 一致；字面量满足 §3.5 约束                 |
| 输出格式   | 整数：纯十进制，无前导零；有符号带 `-`；无符号无后缀；布尔：`true`/`false` |

**形式二：格式化输出**

| 项目       | 说明                                                         |
| ---------- | ------------------------------------------------------------ |
| 语法       | `write(int32, %d, x)`、`write(uint8, %x, 255u)`、`write(bool, %t, flag)` |
| 功能       | 按格式化符号输出操作数的值，**不换行**                       |
| 操作数规则 | 变量或字面量；**恰好一个**操作数                             |
| 类型约束   | 操作数类型与 `type` 一致，且与格式化符号兼容                 |

**特别说明**：`int8` 和 `uint8` 按整数数字输出，而非 ASCII 字符。例如 `write(int8, 65)` 输出 `"65"`。

### 9.2 `writeln` — 换行输出

与 `write` 相同，但在输出末尾追加换行符 `\n`。

```text
var x: int32 = 10
write(int32, x)                    ; "10"
writeln(int32, %d, x)              ; "10\n"

var flag: bool = true
writeln(bool, %t, flag)            ; "true\n"
```

### 9.3 `read` — 标准输入

| 项目     | 说明                                                       |
| -------- | ---------------------------------------------------------- |
| 语法     | `read(int32, x)`、`read(uint8, count)`、`read(bool, flag)` |
| 功能     | 从 stdin 读取一个值，存入已定义变量                        |
| 目标变量 | 必须已声明，且类型与 `type` 一致                           |
| 输入格式 | 见下表；跳过前导空白                                       |
| 错误处理 | 非法输入/数值超范围/非预期 EOF → **I/O 错误**              |

**输入规则**：

| 目标类型 | 输入格式                                      |
| -------- | --------------------------------------------- |
| `int*`   | 可选 `-` 前缀 + 连续十进制数字，至少一位      |
| `uint*`  | 连续十进制数字，至少一位；**不接受** `-` 前缀 |
| `bool`   | `true` 或 `false`（大小写敏感，均为小写）     |

**错误情形**：
1. 数值超出目标类型范围 → I/O 错误
2. EOF 且无有效输入 → I/O 错误
3. `bool` 输入非 `true`/`false` → I/O 错误

### 9.4 格式化符号定义

| 符号 | 含义                    | 适用类型                       | 示例（值 42） |
| ---- | ----------------------- | ------------------------------ | ------------- |
| `%d` | 有符号十进制            | `int8`～`int64`                | `42`          |
| `%i` | 有符号十进制（同 `%d`） | `int8`～`int64`                | `42`          |
| `%u` | 无符号十进制            | `uint8`～`uint64`              | `42`          |
| `%x` | 十六进制（小写 a-f）    | 任一整数类型（按无符号位模式） | `2a`          |
| `%X` | 十六进制（大写 A-F）    | 任一整数类型（按无符号位模式） | `2A`          |
| `%o` | 八进制                  | 任一整数类型（按无符号位模式） | `52`          |
| `%b` | 二进制                  | 任一整数类型（按无符号位模式） | `101010`      |
| `%t` | 布尔值文本              | `bool`                         | `true`        |

**说明**：
- `%x`/`%X`/`%o`/`%b` 在有符号类型上输出其**无符号位模式**（二进制补码解释）
- `%t` 输出 `true` 或 `false`（小写）

### 9.5 类型兼容性

| 符号                      | 可接受操作数类型                      |
| ------------------------- | ------------------------------------- |
| `%d`                      | `int8`, `int16`, `int32`, `int64`     |
| `%i`                      | `int8`, `int16`, `int32`, `int64`     |
| `%u`                      | `uint8`, `uint16`, `uint32`, `uint64` |
| `%x` / `%X` / `%o` / `%b` | 任一整数类型                          |
| `%t`                      | `bool`                                |

**错误示例**：
- `write(int8, %u, x)` ❌（`%u` 要求无符号类型）
- `write(int32, %t, x)` ❌（`%t` 要求 `bool` 类型）
- `write(bool, %d, flag)` ❌（`%d` 要求整数类型）

### 9.6 格式化输出扩展预留

> **扩展预留**：未来版本将支持更多格式化符号：
> - `%f` / `%F`：浮点数（十进制）
> - `%e` / `%E`：浮点数（科学计数法）
> - `%c`：字符
> - `%s`：字符串
> - `%p`：指针
>
> 格式化符号中将支持宽度、精度等修饰符。

## 11. 错误与警告

遇到 **第一个** 错误即终止程序（fail-fast）。错误按发生阶段分为 **静态**（词法/语法/静态分析）与 **运行时** 两类。编译警告不影响程序执行。实现层 `TcErrorKind` 枚举与 §11.1/§11.2 语义类型的对照见 [§11.4](#114-错误码对照表tcerrorkind)。

### 11.1 静态错误

| 错误类型                | 触发条件                                                     |
| ----------------------- | ------------------------------------------------------------ |
| 词法错误                | 非法字符、整数字面量格式非法等                               |
| 语法错误                | token 序列不符合附录 A 的产生式                              |
| 未定义标识符错误        | 使用未 `var`/`let` 声明的标识符                              |
| 重复定义错误            | 同一作用域重复 `var`/`let` 同名标识符                        |
| 类型错误                | 运算或赋值时类型不一致；例如：逻辑运算操作数非 `bool`；`xor` 用于 `bool` 类型；位运算操作数类型与 `T` 不匹配等 |
| 字面量范围错误          | 整数字面量数值超出上下文类型可表示范围                       |
| 字面量类型错误          | `u` 后缀字面量用于有符号类型上下文；负号与 `u` 后缀组合；`true`/`false` 用于非 `bool` 类型；整数用于 `bool` 类型（未通过 `cast`） |
| 关键字错误              | `div`/`mod`/`abs` 使用 `wrap`；`and`/`or`/`xor`/`not`/`shr` 使用 `wrap`；`shl` 使用 `truncate`；`wrap` 用于 `cast`；`truncate` 用于算术运算 |
| 常量赋值错误            | 对 `let` 定义的常量进行赋值                                  |
| 常量表达式错误          | `let` 的 RHS 包含 `var` 变量引用、`wrap`/`truncate` 关键字、缩窄转换，或引用自身/未定义常量 |
| 常量循环依赖错误        | 两个及以上 `let` 常量之间形成循环依赖                        |
| 常量溢出错误            | `let` 常量表达式求值过程中发生有符号算术溢出，或 `shl` 严格模式溢出 |
| 常量除零错误            | `let` 常量表达式中 `div`/`mod` 的除数为 0                    |
| 常量转换溢出错误        | `let` 常量表达式中 `cast` 的值超出目标类型范围               |
| 格式字符串错误          | 格式化符号不是 `%d`/`%i`/`%u`/`%x`/`%X`/`%o`/`%b`/`%t` 之一  |
| 格式类型不匹配          | 操作数类型与格式化符号不兼容                                 |
| 操作数数量错误          | 格式化版本缺少操作数，或多于一个操作数；`and`/`or`/`xor` 操作数数量不为 2；`not` 操作数数量不为 1 |
| 比较类型不匹配          | 比较运算的两操作数类型不一致，或与类型参数不一致             |
| **缩进不一致**          | 同一文件中混用空格和制表符                                   |
| **块内缩进不足**        | 块内语句缩进未比当前块级缩进多（即不大于）                   |
| **`else`/`end` 缩进错** | `else` 或 `end` 的缩进与对应的 `if` 行不一致                 |
| **缺少 `end`**          | `if` 语句未以 `end` 关键字结束                               |
| **`else` 位置错误**     | `else` 前没有对应的 `if` 块（即 `else` 出现在非块结尾位置）  |
| **条件类型错误**        | `if` 的条件 RHS 结果类型不是 `bool`                          |
| **跨块引用局部变量**    | 在变量/常量的作用域（缩进块）之外尝试引用该标识符            |

### 11.2 运行时错误

| 错误类型     | 触发条件                                                     |
| ------------ | ------------------------------------------------------------ |
| 除零错误     | `div`/`mod` 右操作数为 0                                     |
| 整数溢出错误 | 有符号类型严格模式下 `add`/`sub`/`mul`/`neg` 结果超范围；`shl` 严格模式结果超范围 |
| 转换溢出错误 | `cast` 严格模式下结果无法在目标类型中表示                    |
| I/O 错误     | `read` 读取失败                                              |

### 11.3 编译警告

| 警告类型         | 触发条件                                                     |
| ---------------- | ------------------------------------------------------------ |
| 未初始化变量警告 | 读取尚未获得初值的变量。运行时值为 **未定义**（implementation-defined） |

**注意**：短路求值时，未被读取的右操作数不触发未初始化变量警告。

> **实现说明**：`TC_ERR_OUT_OF_MEMORY`（v0.0.24-rev2）将内存不足从 `TC_ERR_SYNTAX` 分离，便于嵌入方区分语法问题与系统资源失败。详细 VM 诊断格式见 [TC-VM详细设计说明书.md](./TC-VM详细设计说明书.md) §11.3。

## 附录 A：形式化语法（EBNF）

本附录为 TC 语言的 **权威语法定义**。语义规则以正文为准。

### A.1 符号约定

采用 **扩展巴科斯-瑙尔范式（EBNF）**：

| 元符号   | 含义              |
| -------- | ----------------- |
| `=`      | 产生式定义        |
| `\|`     | 择一              |
| `[ … ]`  | 可选（0 或 1 次） |
| `{ … }`  | 重复（0 或多次）  |
| `( … )`  | 分组              |
| `"…"`    | 终结符            |
| *斜体名* | 非终结符          |

### A.2 词法

```ebnf
/* ── 基本字符类 ── */

letter     = "A" … "Z" | "a" … "z" | "_" ;
digit      = "0" … "9" ;
hex_digit  = digit | "A" … "F" | "a" … "f" ;

/* ── 标识符与字面量 ── */

identifier = letter , { letter | digit | "_" } ;

integer_literal
           = [ "-" ] , (
               dec_literal [ "u" | "U" ]
             | hex_literal [ "u" | "U" ]
             | bin_literal [ "u" | "U" ]
             | oct_literal [ "u" | "U" ]
           ) ;

bool_literal = "true" | "false" ;

dec_literal = non_zero_digit , { [ "_" ] digit } | "0" ;
hex_literal = ( "0x" | "0X" ) , hex_digit , { [ "_" ] hex_digit } ;
bin_literal = ( "0b" | "0B" ) , ( "0" | "1" ) , { [ "_" ] ( "0" | "1" ) } ;
oct_literal = ( "0o" | "0O" ) , ( "0" … "7" ) , { [ "_" ] ( "0" … "7" ) } ;
non_zero_digit = "1" … "9" ;

/* 数字分隔符说明：下划线 "_" 仅用于可读性分隔，无语义。
   不允许连续两个下划线，也不允许下划线出现在字面量首尾。 */

/* ── 类型关键字 ── */

int_type   = "int8"   | "uint8"
           | "int16"  | "uint16"
           | "int32"  | "uint32"
           | "int64"  | "uint64" ;
bool_type  = "bool" ;
type       = int_type | bool_type ;
/* 扩展预留：浮点类型 float32, float64；复合类型 array, struct, ptr */

/* ── 运算与模式关键字 ── */

binary_arith_op = "add" | "sub" | "mul" | "div" | "mod" ;
unary_arith_op  = "abs" | "neg" ;
bitwise_op      = "and" | "or" | "xor" ;           /* 按位逻辑，也用于布尔逻辑，由类型参数区分 */
unary_bitwise_op = "not" ;                         /* 按位非，也用于布尔非 */
shift_op        = "shl" | "shr" ;
compare_op = "eq" | "ne" | "lt" | "le" | "gt" | "ge" ;
wrap_kw    = "wrap" ;
truncate_kw = "truncate" ;

/* ── 格式化符号 ── */

format_specifier
           = "%d" | "%i" | "%u" | "%x" | "%X" | "%o" | "%b" | "%t" ;
/* 扩展预留：%f, %F, %e, %E, %c, %s, %p */

/* ── 控制流关键字 ── */
if_kw      = "if" ;
then_kw    = "then" ;
else_kw    = "else" ;
end_kw     = "end" ;

/* ── 注释 ── */

line_comment = ";" , { ? any character except newline ? } ;
```

### A.3 语法

```ebnf
/* ── 程序 ── */

program    = { ( statement , [ stmt_terminator ] , newline )
             | ws , [ line_comment ] , newline }
             [ ( statement , [ stmt_terminator ] )
             | ws , [ line_comment ] ] ;

statement  = variable_def
           | constant_def
           | assignment
           | write_stmt
           | writeln_stmt
           | read_stmt
           | if_stmt ;

/* ── 变量定义 ── */

variable_def = "var" , ws , identifier , ws , ":" , ws , type
             [ ws , "=" , ws , rhs ] ;

/* ── 常量定义 ── */

constant_def = "let" , ws , identifier , ws , ":" , ws , type , ws ,
               "=" , ws , const_rhs ;

/* ── 赋值语句 ── */

assignment = identifier , ws , "=" , ws , rhs ;

stmt_terminator
           = ";" , [ { ? any character except newline ? } ]
           | ws , line_comment ;

/* ── if 语句（缩进敏感，end 必须） ── */

if_stmt    = "if" , ws , rhs , ws , "then" , newline ,
             indented_block
             [ newline , "else" , newline ,
               indented_block ]
             newline , "end" ;

indented_block
           = { indented_stmt , newline } ;

indented_stmt
           = ws , statement , [ stmt_terminator ] ;
/* indented_stmt 的行首 ws 须比 enclosing if/else 行多至少一个缩进级别；
   end 行缩进须与对应的 if 行一致。缩进语义见 §4.7.2。 */

/* ── 右值表达式 ── */

rhs        = integer_literal
           | bool_literal
           | binary_arith_expr
           | unary_arith_expr
           | bitwise_expr          /* 按位 and/or/xor，双目 */
           | unary_bitwise_expr    /* 按位 not，单目 */
           | shift_expr
           | compare_expr
           | binary_logic_expr
           | unary_logic_expr
           | cast_expr ;

/* ── 常量右值表达式 ── */

const_rhs  = integer_literal
           | bool_literal
           | identifier                     /* 已定义的 let 常量引用 */
           | const_binary_arith_expr
           | const_unary_arith_expr
           | const_bitwise_expr
           | const_unary_bitwise_expr
           | const_shift_expr
           | const_compare_expr
           | const_binary_logic_expr
           | const_unary_logic_expr
           | const_cast_expr ;

/* ── 常量算术表达式（不含 wrap） ── */

const_binary_arith_expr
           = binary_arith_op , "(" , ws , int_type , ws , ","
             , ws , const_operand , ws , "," , ws , const_operand , ws , ")" ;

const_unary_arith_expr
           = unary_arith_op , "(" , ws , int_type , ws , ","
             , ws , const_operand , ws , ")" ;

/* ── 常量位运算表达式（不含 wrap） ── */

const_bitwise_expr
           = bitwise_op , "(" , ws , int_type , ws , ","
             , ws , const_operand , ws , "," , ws , const_operand , ws , ")" ;
/* bitwise_op ∈ { and, or, xor } */

const_unary_bitwise_expr
           = "not" , "(" , ws , int_type , ws , ","
             , ws , const_operand , ws , ")" ;

const_shift_expr
           = shift_op , "(" , ws , int_type , ws , ","
             , ws , const_operand , ws , "," , ws , const_operand , ws , ")" ;
/* 常量表达式中 shift_op 允许 shl（无wrap，溢出即报错）和 shr */

/* ── 常量比较表达式 ── */

const_compare_expr
           = compare_op , "(" , ws , int_type , ws , ","
             , ws , const_operand , ws , "," , ws , const_operand , ws , ")" ;

/* ── 常量逻辑表达式 ── */

const_binary_logic_expr
           = binary_logic_op , "(" , ws , bool_type , ws , ","
             , ws , const_operand , ws , "," , ws , const_operand , ws , ")" ;

const_unary_logic_expr
           = "not" , "(" , ws , bool_type , ws , ","
             , ws , const_operand , ws , ")" ;

/* ── 常量转换表达式（无 truncate） ── */

const_cast_expr
           = "cast" , "(" , ws , type , ws , ","
             , ws , const_operand , ws , ")" ;

/* ── 常量操作数 ── */

const_operand
           = integer_literal
           | bool_literal
           | identifier ;                   /* 已定义的 let 常量引用 */

/* ── 操作数 ── */

operand    = identifier | integer_literal | bool_literal ;

/* ── 双目算术表达式 ── */

binary_arith_expr
           = strict_binary_arith_expr
           | wrap_binary_arith_expr ;

strict_binary_arith_expr
           = binary_arith_op , "(" , ws , int_type , ws , ","
             , ws , operand , ws , "," , ws , operand , ws , ")" ;

wrap_binary_arith_expr
           = binary_arith_op , "(" , ws , int_type , ws , ","
             , ws , wrap_kw , ws , ","
             , ws , operand , ws , "," , ws , operand , ws , ")" ;

/* binary_arith_op ∈ { add, sub, mul, div, mod }
   wrap 形式仅 add/sub/mul 合法；div/mod 使用则报错 */

/* ── 单目算术表达式 ── */

unary_arith_expr
           = strict_unary_arith_expr
           | wrap_unary_arith_expr ;

strict_unary_arith_expr
           = unary_arith_op , "(" , ws , int_type , ws , ","
             , ws , operand , ws , ")" ;

wrap_unary_arith_expr
           = unary_arith_op , "(" , ws , int_type , ws , ","
             , ws , wrap_kw , ws , ","
             , ws , operand , ws , ")" ;

/* unary_arith_op ∈ { abs, neg }
   wrap 形式仅 neg 合法；abs 使用 wrap 则报错 */

/* ── 按位逻辑表达式（双目） ── */

bitwise_expr
           = bitwise_op , "(" , ws , int_type , ws , ","
             , ws , operand , ws , "," , ws , operand , ws , ")" ;
/* bitwise_op ∈ { and, or, xor } */

/* ── 按位非表达式（单目） ── */

unary_bitwise_expr
           = "not" , "(" , ws , int_type , ws , ","
             , ws , operand , ws , ")" ;

/* ── 移位表达式 ── */

shift_expr
           = strict_shift_expr
           | wrap_shift_expr ;

strict_shift_expr
           = shift_op , "(" , ws , int_type , ws , ","
             , ws , operand , ws , "," , ws , operand , ws , ")" ;

wrap_shift_expr
           = "shl" , "(" , ws , int_type , ws , ","
             , ws , wrap_kw , ws , ","
             , ws , operand , ws , "," , ws , operand , ws , ")" ;
/* wrap 仅允许 shl，shr 不允许 wrap */

/* ── 比较表达式 ── */

compare_expr = compare_op , "(" , ws , int_type , ws , ","
               , ws , operand , ws , "," , ws , operand , ws , ")" ;

/* compare_op ∈ { eq, ne, lt, le, gt, ge }
   两操作数须为相同整数类型，返回 bool */

/* ── 双目逻辑表达式（布尔） ── */

binary_logic_expr
           = binary_logic_op , "(" , ws , bool_type , ws , ","
             , ws , operand , ws , "," , ws , operand , ws , ")" ;

binary_logic_op = "and" | "or" ;

/* ── 单目逻辑表达式（布尔） ── */

unary_logic_expr
           = "not" , "(" , ws , bool_type , ws , ","
             , ws , operand , ws , ")" ;

/* ── 类型转换表达式 ── */

cast_expr  = strict_cast_expr | truncate_cast_expr ;

strict_cast_expr
           = "cast" , "(" , ws , type , ws , ","
             , ws , operand , ws , ")" ;

truncate_cast_expr
           = "cast" , "(" , ws , int_type , ws , ","
             , ws , truncate_kw , ws , ","
             , ws , operand , ws , ")" ;

/* cast 源操作数须为变量，不可为字面量或嵌套表达式
   truncate 仅用于整数 → 整数转换；bool ↔ 整数转换中 truncate 与 strict 行为相同，但语法上不允许 truncate 用于 bool 目标 */

/* ── I/O 语句 ── */

write_stmt = "write" , "(" , ws , type , ws , ","
             , ws , operand , ws , ")"
           | "write" , "(" , ws , type , ws , ","
             , ws , format_specifier , ws , ","
             , ws , operand , ws , ")" ;

writeln_stmt = "writeln" , "(" , ws , type , ws , ","
               , ws , operand , ws , ")"
             | "writeln" , "(" , ws , type , ws , ","
               , ws , format_specifier , ws , ","
               , ws , operand , ws , ")" ;

read_stmt  = "read" , "(" , ws , type , ws , ","
             , ws , identifier , ws , ")" ;

/* ── 空白 ── */

ws         = { " " | "\t" } ;
newline    = "\n" | "\r\n" | "\r" ;
```

## 附录 B：与 C 语言整数语义对照

### B.1 类型与运算对照

| 类型        | TC 类型  | C 语言等价                     |
| ----------- | -------- | ------------------------------ |
| 8 位有符号  | `int8`   | `int8_t`                       |
| 8 位无符号  | `uint8`  | `uint8_t`                      |
| 16 位有符号 | `int16`  | `int16_t`                      |
| 16 位无符号 | `uint16` | `uint16_t`                     |
| 32 位有符号 | `int32`  | `int32_t`                      |
| 32 位无符号 | `uint32` | `uint32_t`                     |
| 64 位有符号 | `int64`  | `int64_t`                      |
| 64 位无符号 | `uint64` | `uint64_t`                     |
| 布尔        | `bool`   | `bool`（C23） / `_Bool`（C99） |

| 运算              | TC                                    | C 等价                                         |
| ----------------- | ------------------------------------- | ---------------------------------------------- |
| 有符号字面量      | `42`                                  | `42`                                           |
| 无符号字面量      | `42u`                                 | `42u`                                          |
| 布尔字面量        | `true` / `false`                      | `true` / `false`（C23）                        |
| 加                | `add(int32, a, b)`                    | `(int32_t)a + (int32_t)b`                      |
| 加（回绕）        | `add(int32, wrap, a, b)`              | 同宽无符号运算后 reinterpret                   |
| 减 / 乘           | `sub` / `mul`                         | 对应 `-` / `*`                                 |
| 整除 / 求余       | `div` / `mod`                         | `/` / `%`（`INT_MIN / −1` 在 C 为 UB）         |
| `div(INT_MIN,−1)` | `div` → **整数溢出错误**；`mod` → `0` | C 为 **UB**（Java/C# 定义 `div` 为 `INT_MIN`） |
| 取绝对值          | `abs(int32, a)`                       | `llabs(a)`                                     |
| 取负数            | `neg(int32, a)`                       | `-a`                                           |
| 取负数（回绕）    | `neg(int32, wrap, a)`                 | 同宽无符号运算后 reinterpret                   |
| 按位与            | `and(int32, a, b)`                    | `a & b`                                        |
| 按位或            | `or(int32, a, b)`                     | `a \| b`                                       |
| 按位异或          | `xor(int32, a, b)`                    | `a ^ b`                                        |
| 按位非            | `not(int32, a)`                       | `~a`                                           |
| 左移（严格）      | `shl(int32, a, b)`                    | `a << b`（TC 检测溢出，C 为 UB）               |
| 左移（回绕）      | `shl(int32, wrap, a, b)`              | `(uint32_t)a << b` 后 reinterpret（无 UB）     |
| 右移（有符号）    | `shr(int32, a, b)`                    | `a >> b`（TC 固定算术右移，C 为实现定义）      |
| 右移（无符号）    | `shr(uint32, a, b)`                   | `a >> b`（逻辑右移，两者一致）                 |
| 相等比较          | `eq(int32, a, b)`                     | `a == b`                                       |
| 小于比较          | `lt(int32, a, b)`                     | `a < b`                                        |
| 逻辑与            | `and(bool, a, b)`                     | `a && b`                                       |
| 逻辑或            | `or(bool, a, b)`                      | `a \|\| b`                                     |
| 逻辑非            | `not(bool, a)`                        | `!a`                                           |

| 转换                   | TC                        | C                                 |
| ---------------------- | ------------------------- | --------------------------------- |
| 严格模式（默认）       | `cast(int8, a)`           | `(int8_t)a`（不可表示时 TC 报错） |
| 截断模式（`truncate`） | `cast(int8, truncate, a)` | `(int8_t)a`（按位截断）           |
| bool→int               | `cast(int32, flag)`       | `flag ? 1 : 0`                    |
| int→bool               | `cast(bool, x)`           | `x != 0`                          |

| I/O          | TC                     | C 等价             |
| ------------ | ---------------------- | ------------------ |
| 无格式输出   | `write(int32, x)`      | `printf("%d", x)`  |
| 有符号十进制 | `write(int32, %d, x)`  | `printf("%d", x)`  |
| 无符号十进制 | `write(uint32, %u, x)` | `printf("%u", x)`  |
| 十六进制小写 | `write(uint32, %x, x)` | `printf("%x", x)`  |
| 十六进制大写 | `write(uint32, %X, x)` | `printf("%X", x)`  |
| 八进制       | `write(uint32, %o, x)` | `printf("%o", x)`  |
| 二进制       | `write(uint32, %b, x)` | 无标准等价（扩展） |
| 布尔输出     | `write(bool, %t, x)`   | 无标准等价（扩展） |

**主要差异**：
- TC 严格模式下有符号溢出报错（C 为 UB）
- TC `div(INT_MIN, −1)` 报整数溢出错误（C 为 UB；Java/C# 将 `div` 定义为 `INT_MIN`）
- TC `cast` 严格模式对不可表示转换报错（C 为实现定义/UB）
- TC 读取未初始化变量为编译警告 + 实现定义值（C 为 UB）
- TC 二进制 `%b` 和布尔 `%t` 为扩展格式
- TC 比较运算返回 `bool`（C 中比较返回 `int`）
- TC 逻辑运算严格操作 `bool`（C 中逻辑运算接受任意标量类型）
- TC 右移有符号固定算术右移，C 为实现定义

| 溢出检查           | ✅ 编译期报错 | ❌ UB         | TC 在编译期捕获常量溢出 |
| 优化器可推导       | ✅ 恒为常量   | ⚠️ 视实现而定 | TC 语义保证             |
