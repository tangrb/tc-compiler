## 1. 概述

### 1.1 语言定位

TC 是一门伪汇编语言：语法接近高级语言的赋值表达式，执行模型保留汇编式的 **逐条语句** 顺序执行。每条语句至多包含 **一个** 运算或转换调用，**不支持** 表达式嵌套。

本文档定义：

- **8 种** 固定宽度整数类型（`int8`～`uint64`）
- **7 类** 算术运算指令：
  - 双目运算（5 类）：`add`、`sub`、`mul`、`div`、`mod`
  - 单目运算（2 类）：`abs`（取绝对值）、`neg`（取负数）
- **1 类** 类型转换指令：`cast`
- **3 条** 标准 I/O 语句：`write`、`writeln`、`read`
  - `write`/`writeln` 支持格式化输出（7 种格式化符号）
- 算术回绕模式关键字 **`wrap`**（用于 `add`/`sub`/`mul`/`neg`）
- 类型转换截断模式关键字 **`truncate`**（用于 `cast`）

### 1.2 设计原则

| 原则           | 说明                                                         |
| -------------- | ------------------------------------------------------------ |
| 声明与赋值分离 | 首次定义使用 `var`，后续修改省略 `var`                       |
| 常量与变量分离 | 不可变常量使用 `let` 定义，须在编译期初始化                  |
| 显式类型标注   | 变量/常量定义须声明具体整数类型                              |
| 运算函数化     | 算术以 `op(<类型> [, wrap], 操作数...)` 形式调用（`div`/`mod`/`abs` 无 `wrap`） |
| 类型参数首位   | 运算与转换的类型均作为 **第一个参数** 显式给出               |
| 默认严格溢出   | 有符号 `add`/`sub`/`mul`/`neg` 与 `cast` 默认检测溢出并报错；回绕或位截断须显式传入对应关键字 |
| 同类型运算     | 同一运算的操作数须为相同整数类型                             |
| 显式类型转换   | 跨类型须通过 `cast` 完成，禁止隐式转换                       |
| 逐条执行       | 每条语句独立执行，无隐式表达式嵌套求值                       |
| 字面量类型显式 | 无后缀字面量为有符号整数；`u`/`U` 后缀字面量为无符号整数     |
| I/O 格式化     | `write`/`writeln` 支持格式化符号，单符号单操作数             |

### 1.3 设计哲学

TC 的设计遵循以下核心理念：

| 理念             | 说明                                                         |
| ---------------- | ------------------------------------------------------------ |
| **显式优于隐式** | 类型转换、溢出处理、符号性均须显式标注，杜绝隐式歧义         |
| **安全优先**     | 默认检测溢出和转换错误，将运行时可预测性置于性能之上         |
| **教学友好**     | 伪汇编风格让底层概念（位宽、符号、溢出、截断）直观可见       |
| **渐进扩展**     | 当前聚焦整数子集，为未来浮点、布尔、复合类型预留清晰的设计空间 |

### 1.4 完整示例

以下是一个完整的 TC 程序，展示语言的核心能力：

```text
; ============================================================
; 变量与常量定义
; ============================================================
var a: int32 = 10
var b: int32 = 20
let SCALE: int32 = 1000

; ============================================================
; 算术运算
; ============================================================
var sum: int32 = add(int32, a, b)           ; 30
var diff: int32 = sub(int32, a, b)          ; -10
var prod: int32 = mul(int32, a, b)          ; 200
var quot: int32 = div(int32, b, a)          ; 2
var rem: int32 = mod(int32, b, a)           ; 0

; ============================================================
; 回绕示例
; ============================================================
var max_i8: int8 = 127
var one: int8 = 1
var wrapped: int8 = add(int8, wrap, max_i8, one)  ; -128

; ============================================================
; 类型转换
; ============================================================
var scaled: int32 = mul(int32, sum, SCALE)
var result_i8: int8 = cast(int8, truncate, scaled)  ; 截断

; ============================================================
; I/O
; ============================================================
write(int32, %d, sum)                      ; 输出 "30"
writeln(int32, %d, scaled)                 ; 输出 "30000\n"
```

## 2. 词法结构

本章定义 TC 语言的基本词法单元。完整的 EBNF 定义见附录 A。

### 2.1 字符集与 Token

TC 源文件由以下字符构成：

- **字母**：`A`–`Z`、`a`–`z`、`_`
- **数字**：`0`–`9`
- **符号**：`+`、`-`、`*`、`/`、`%`、`=`、`:`、`,`、`(`、`)`、`;`、`_`
- **空白**：空格、制表符（`\t`）、换行符（`\n`、`\r\n`、`\r`）

源文件编码为 **UTF-8**，但语言关键字和标识符仅限于 ASCII 字符集。

### 2.2 标识符

- 由字母、数字与 `_` 组成，**必须以字母开头**（字母包含 `_`）。
- **区分大小写**：`a` 与 `A` 为不同变量。
- 合法：`a`、`count`、`_tmp1`、`my_var`
- 非法：`1a`、`-x`（`-` 非标识符字符）

### 2.3 整数字面量

#### 2.3.1 后缀与符号性

TC 字面量通过后缀区分符号性：

| 后缀      | 符号性     | 示例                   |
| --------- | ---------- | ---------------------- |
| 无后缀    | 有符号整数 | `42`、`-128`、`0xFF`   |
| `u` / `U` | 无符号整数 | `42u`、`255u`、`0xFFu` |

**关键规则**：
- 无后缀字面量视为有符号整数，可用于有符号类型上下文；若用于无符号上下文，须满足范围约束
- `u` 后缀字面量视为无符号整数，**仅可用于无符号类型上下文**；用于有符号上下文触发 **字面量类型错误**
- 负号 `-` **仅可与无后缀字面量**组合；`-42u` 为非法

#### 2.3.2 进制

TC 支持四种进制字面量：

| 进制           | 前缀        | 数字字符集                | 示例                      |
| -------------- | ----------- | ------------------------- | ------------------------- |
| 十进制（默认） | —           | `0`–`9`                   | `0`、`255`、`-128`、`42u` |
| 十六进制       | `0x` / `0X` | `0`–`9`、`a`–`f`、`A`–`F` | `0xFF`、`0x1Au`、`-0x80`  |
| 二进制         | `0b` / `0B` | `0`、`1`                  | `0b1010`、`0b11111111u`   |
| 八进制         | `0o` / `0O` | `0`–`7`                   | `0o377`、`-0o100`         |

- 前缀中的 `0` 是必需的前导，**不区分大小写**
- 前缀与数字之间 **不可有空白**
- 后缀紧跟数字部分，前缀与后缀之间 **不可有空白**

#### 2.3.3 数字分隔符

为增强长数字的可读性，允许在下述位置插入单个下划线 `_`：

- 十进制：数字之间（首数字之后，末数字之前）
- 十六进制：`0x`/`0X` 与末数字之间
- 二进制：`0b`/`0B` 与末数字之间
- 八进制：`0o`/`0O` 与末数字之间

示例：

```text
1_000_000           → 1000000
0xFFFF_0000u        → 4294901760
0b1010_0011u        → 163
-0x7F_FF            → -32767
```

**约束**：不可连续两个 `_`，不可在字面量首尾放置 `_`，不可在前缀内部插入 `_`（如 `0x_FF` 非法）。

#### 2.3.4 前导零

- 十进制字面量 **不允许前导零**（`007` **非法**，应写作 `7`）
- 单个 `0` 是合法的十进制零，不视为前导零特例
- 八进制须显式使用 `0o` 前缀

#### 2.3.5 字面量的词法上限

- 字面量的**数值**不得超过 `uint64` 范围：`0 ≤ N ≤ 18446744073709551615`
- 字面量超出此范围 → **字面量范围错误**

#### 2.3.6 负号与减法运算符的关系

`-` 前缀仅出现在无后缀整数字面量中，**不作为独立的一元运算符**。若需变量间的减法，使用 `sub` 指令。

#### 2.3.7 词法分析器匹配策略

词法分析器采用 **最长匹配** 策略：
1. 扫描 `0` 时，检查后续字符是否为 `x`/`X`/`b`/`B`/`o`/`O`，转入对应进制
2. 数字部分扫描完成后，检查后续字符是否为 `u`/`U`，归约为带后缀字面量
3. 否则归约为无后缀字面量

### 2.4 浮点字面量（预留）

> **扩展预留**：未来版本将支持浮点字面量，语法形式为：
> - 十进制浮点：`3.14`、`-0.5`、`1.0`
> - 科学计数法：`1.2e5`、`-3.14E-2`
> - 后缀：`f`（`float32`）、无后缀（`float64`）
>
> 当前版本中，包含 `.` 或 `e`/`E` 的数字序列为 **词法错误**。

### 2.5 字符与字符串字面量（预留）

> **扩展预留**：未来版本将支持：
> - 字符字面量：`'a'`、`'\n'`、`'\x41'`
> - 字符串字面量：`"hello"`、`"world\n"`
>
> 当前版本中，单引号或双引号包裹的内容为 **词法错误**。

### 2.6 注释

- 行注释以 `;` 开始，延续至行尾
- 示例：`var a: int32 = 10    ; 定义 32 位整数`

### 2.7 关键字

以下 token 为保留关键字，不可用作标识符：

```text
var  let  int8  uint8  int16  uint16  int32  uint32  int64  uint64
add  sub  mul  div  mod  abs  neg  cast  wrap  truncate  write  writeln  read
```

> **扩展预留**：以下关键字为未来功能保留：`if`、`else`、`goto`、`loop`、`func`、`return`、`true`、`false`、`bool`、`float32`、`float64`、`string`、`array`、`struct`、`ptr`、`and`、`or`、`xor`、`shl`、`shr`、`eq`、`ne`、`lt`、`le`、`gt`、`ge`、`not`。

### 2.8 语句与行结构

- 每条语句独占一行
- **空行**、**仅含空白符的行**、**仅含行注释**的行均合法，不产生语句
- 语句末尾 `;` **可选**；`;` 同时起语句结束和注释标记作用，其后内容均视为注释

## 3. 类型系统

### 3.1 类型分类

TC 的类型系统设计为可扩展的分类体系。当前支持 **整数类型**，未来将逐步引入其他类别：

| 类别            | 当前支持           | 未来预留                 | 说明                   |
| --------------- | ------------------ | ------------------------ | ---------------------- |
| **整数类型**    | ✅ `int8`～`uint64` | `int128`、`uint128`      | 固定宽度二进制补码整数 |
| **浮点类型**    | —                  | `float32`、`float64`     | IEEE 754 浮点数        |
| **布尔类型**    | —                  | `bool`                   | 逻辑真/假              |
| **字符/字符串** | —                  | `char`、`string`         | Unicode 字符与字符串   |
| **复合类型**    | —                  | `array`、`struct`、`ptr` | 聚合与间接类型         |
| **单位类型**    | —                  | `void`                   | 无值（用于函数返回）   |

### 3.2 当前支持的整数类型

| 类型     | 位宽 | 符号   | 最小值                     | 最大值                     |
| -------- | ---- | ------ | -------------------------- | -------------------------- |
| `int8`   | 8    | 有符号 | −128                       | 127                        |
| `uint8`  | 8    | 无符号 | 0                          | 255                        |
| `int16`  | 16   | 有符号 | −32,768                    | 32,767                     |
| `uint16` | 16   | 无符号 | 0                          | 65,535                     |
| `int32`  | 32   | 有符号 | −2,147,483,648             | 2,147,483,647              |
| `uint32` | 32   | 无符号 | 0                          | 4,294,967,295              |
| `int64`  | 64   | 有符号 | −9,223,372,036,854,775,808 | 9,223,372,036,854,775,807  |
| `uint64` | 64   | 无符号 | 0                          | 18,446,744,073,709,551,615 |

类型命名规则：`<符号前缀><位宽>`，其中符号前缀为 `int`（有符号）或 `uint`（无符号），位宽为 `8`/`16`/`32`/`64`。

### 3.3 类型性质

**有符号类型（`int8`～`int64`）**

- 采用 **二补码** 表示
- `add`/`sub`/`mul`/`neg` 默认 **strict**：结果超出范围 → **整数溢出错误**
- 显式 `wrap` 模式：按模 2^n 回绕，不报错

**无符号类型（`uint8`～`uint64`）**

- 仅表示非负整数
- 算术结果超出最大值时 **模 2^n 回绕**，不报错
- `div`/`mod` 结果恒为非负

**运行时值模型**

TC 中每个变量的值由 **n 位位模式**（`n` 为类型位宽）与 **类型解释** 共同构成：

- 内部以 n 位无符号位模式存储；有符号类型按 **二补码** 解释，无符号类型按非负整数解释
- `wrap` 算术回绕与 `cast(..., truncate, ...)` 均在此位模式上操作
- 有符号 `wrap` 下的 `add`/`sub`/`mul`/`neg` 与同位宽无符号默认回绕 **位模式一致**

### 3.4 字面量与类型的关系

整数字面量的符号性由后缀决定，数值须满足上下文类型的约束：

```text
; 有符号字面量（无后缀）——可用于有符号类型
var a: int8 = 127           ; 合法
var b: int8 = 128           ; 字面量范围错误
var c: int32 = -100         ; 合法

; 有符号字面量用于无符号类型——需满足范围
var e: uint8 = 255          ; 合法
var f: uint8 = 256          ; 字面量范围错误
var g: uint8 = -1           ; 字面量范围错误

; 无符号字面量（u 后缀）——仅可用于无符号类型
var h: uint8 = 255u         ; 合法
var j: int32 = 42u          ; 字面量类型错误
```

#### 字面量检查规则

1. 解析字面量数值 `N`（`0 ≤ N ≤ 18446744073709551615`）
2. 若带负号（仅无后缀字面量允许），取 `−N`（`N=0` 时 `−0 = 0`）
3. 根据后缀确定符号性：
   - 无后缀 → 有符号
   - `u`/`U` 后缀 → 无符号
4. 检查上下文类型：
   - 有符号类型：仅允许无后缀字面量，值在范围内
   - 无符号类型：允许无后缀（≥0）或 `u` 后缀字面量，值在范围内
5. 不满足则报错

| 上下文类型 | 允许的字面量形式        | 可接受数值范围                                          |
| ---------- | ----------------------- | ------------------------------------------------------- |
| `int8`     | 无后缀                  | −128 ～ 127                                             |
| `uint8`    | 无后缀（≥0）或 `u` 后缀 | 0 ～ 255                                                |
| `int16`    | 无后缀                  | −32,768 ～ 32,767                                       |
| `uint16`   | 无后缀（≥0）或 `u` 后缀 | 0 ～ 65,535                                             |
| `int32`    | 无后缀                  | −2,147,483,648 ～ 2,147,483,647                         |
| `uint32`   | 无后缀（≥0）或 `u` 后缀 | 0 ～ 4,294,967,295                                      |
| `int64`    | 无后缀                  | −9,223,372,036,854,775,808 ～ 9,223,372,036,854,775,807 |
| `uint64`   | 无后缀（≥0）或 `u` 后缀 | 0 ～ 18,446,744,073,709,551,615                         |

**`wrap`/`truncate` 不绕过字面量检查**：即使运算或转换使用回绕/截断模式，字面量仍须在上下文类型范围内通过静态检查。

### 3.5 类型转换的通用框架

TC 的所有类型转换统一使用 `cast` 指令。转换行为由以下维度决定：

| 维度         | 说明                                                         |
| ------------ | ------------------------------------------------------------ |
| **源类型**   | 当前值的类型                                                 |
| **目标类型** | 要转换到的类型                                               |
| **模式**     | `strict`（默认）：数值可表示性检查；`truncate`：按位截断/扩展/重解释 |

当前实现的转换规则针对整数类型。未来扩展浮点、布尔、复合类型时，将复用此框架，补充各类型特定的转换语义。

### 3.6 作用域

TC 采用 **单全局作用域**：

- 所有 `var` 和 `let` 定义的标识符同属一个全局命名空间
- **无** 块级作用域、函数作用域或局部变量
- 同一作用域内不可重复定义
- **源序可见性**：变量/常量在定义语句执行之后才可供后续语句引用
- 定义自身的 RHS **不可引用自身**，亦不可引用尚未定义的标识符

> **扩展预留**：未来引入函数时，将增加函数级局部作用域，作用域规则将相应扩展。

### 3.7 变量生命周期

| 阶段             | 行为                                                    |
| ---------------- | ------------------------------------------------------- |
| 静态分析         | 解析所有 `var`/`let` 定义，建立符号表                   |
| `var` 语句执行   | 若有 RHS，计算并写入；若无 RHS，保持 **未初始化**       |
| 未初始化变量读取 | **编译警告**，值为 **未定义**（implementation-defined） |
| `let` 语句执行   | 常量值在编译期确定，不生成运行时指令                    |
| 赋值语句执行     | 更新对应存储位置                                        |
| `read` 语句执行  | 从 stdin 读入值并写入目标变量，视为 **初始化**          |
| 程序终止         | 所有变量值失效                                          |

## 4. 程序结构与语句

### 4.1 程序构成

TC 源文件由若干 **行** 组成，每行至多一条语句。程序执行的入口为文件的第一条非空、非注释语句，按顺序执行至文件末尾。

**程序结构约束**：
- 源文件由若干行组成；每行至多一条语句
- 空行、纯注释行均合法，不产生语句
- 语句末尾 `;` 可选；`;` 同时起语句结束和注释标记作用

### 4.2 变量定义（`var`）

使用 `var` 声明变量。RHS **可选**：

- **有 RHS**：声明并初始化变量
- **无 RHS**：声明变量，其值初始为 **未定义**

同一作用域内不可重复定义同名变量。跨类型赋值须先 `cast`。

```text
var a: int32 = 10           ; 声明并初始化
var b: int32                ; 声明但未初始化
var c: int32 = add(int32, a, 20)  ; 合法（a 已初始化）
var d: int8 = cast(int8, truncate, a)
```

### 4.3 常量定义（`let`）

使用 `let` 声明 **不可变常量**：

- RHS **必须** 提供
- RHS 须为 **编译期常量表达式**（当前版本仅支持整数字面量）
- 常量在编译期求值，不生成运行时赋值指令
- 常量 **不可** 作为赋值语句的左值
- 常量名不可与变量名冲突

```text
let PI: int32 = 31415
let MASK: uint32 = 0xFFFF_0000u
let X: int32 = add(int32, 10, 20)  ; 静态错误：let RHS 仅允许字面量
```

### 4.4 赋值语句

对已定义变量重新赋值时 **省略** `var`。右侧结果类型须与变量已声明类型 **完全一致**。

```text
var c: int32 = add(int32, a, b)
c = mul(int32, a, b)        ; 合法
c = cast(int32, d)          ; 跨类型须先 cast
```

**约束**：赋值左侧不可为 `let` 定义的常量。

### 4.5 右值表达式（RHS）

| 产生式              | 结果类型           | 说明                         |
| ------------------- | ------------------ | ---------------------------- |
| `integer_literal`   | 由左侧变量类型决定 | 须满足字面量符号性及范围约束 |
| `binary_arith_expr` | 第一参数类型       | 五种双目算术运算             |
| `unary_arith_expr`  | 第一参数类型       | 两种单目算术运算             |
| `cast_expr`         | 第一参数类型       | 类型转换                     |

### 4.6 操作数（Operand）

| 形式              | 约束                                                         |
| ----------------- | ------------------------------------------------------------ |
| *identifier*      | 已定义，且类型与运算类型一致；若为变量且未初始化 → **编译警告** |
| *integer_literal* | 须满足字面量约束                                             |

**不支持** 嵌套：操作数不可为算术表达式或 `cast` 表达式。复合计算须拆分为多条语句。

### 4.7 控制流与函数（预留）

> **扩展预留**：未来版本将支持：
> - 控制流：`label`、`goto`、`if`、`loop`
> - 函数：`func` 定义与 `call` 调用
>
> 当前版本不支持任何控制流语句或函数定义。

## 5. 算术运算

### 5.1 `wrap` 模式详解

`add`、`sub`、`mul`（双目）和 `neg`（单目）支持可选的 `wrap` 参数；`div`、`mod`、`abs` **不支持**。

| 调用形式                     | 模式           | 有符号（`int8`～`int64`） | 无符号（`uint8`～`uint64`） |
| ---------------------------- | -------------- | ------------------------- | --------------------------- |
| `<op>(<T>, 操作数...)`       | strict（默认） | 超范围 → **整数溢出错误** | 超最大值 → **模 2^n 回绕**  |
| `<op>(<T>, wrap, 操作数...)` | wrap           | 超范围 → **模 2^n 回绕**  | 与三参数形式相同            |

其中 `<op>` ∈ {`add`, `sub`, `mul`, `neg`}；n 为 `<T>` 位宽。

**回绕规则**：先按 `<T>` 的位宽与符号性计算算术结果，再取 mod 2^n，将无符号位模式解释为目标类型值。有符号 `wrap` 下的运算与同位宽无符号默认回绕 **位模式一致**。

**strict 溢出检测**（`add`/`sub`/`mul`/`neg`，有符号类型）：

1. 将操作数按 `<T>` 解码为 int64 有符号值
2. 在 int64 域执行对应运算；若 int64 本身溢出 → **整数溢出错误**
3. 若结果不在 `<T>` 的可表示范围内 → **整数溢出错误**
4. 将结果编码为 `<T>` 的 n 位位模式

**等效位级定义**：
- **`add`**：两个正数之和为负数，或两个负数之和为正数 → 溢出
- **`sub`**：正数减负数得负数，或负数减正数得正数 → 溢出
- **`mul`**：乘积符号与数学整数运算不一致，或绝对值超出目标类型范围 → 溢出
- **`neg`**：操作数为 `INT_MIN` → 溢出

**约束**：
- `wrap` 可用于：`add`、`sub`、`mul`、`neg`
- `div`/`mod` 使用 `wrap` → **溢出模式错误**
- `abs` 使用 `wrap` → **溢出模式错误**
- `cast` 使用 `wrap` → **关键字错误**

```text
var a: int8 = 127
var b: int8 = 1
var c: int8 = add(int8, a, b)               ; 整数溢出错误
var d: int8 = add(int8, wrap, a, b)         ; d = -128
```

### 5.2 整数有符号运算（`int8`～`int64`）

| 指令                  | 语义                                                         |
| --------------------- | ------------------------------------------------------------ |
| `add` / `sub` / `mul` | 和 / 差 / 积；strict 超范围报错，wrap 回绕                   |
| `div`                 | 商，**向零截断**（同 C 有符号 `/`）；除数为 0 → **除零错误**；商不可表示 → **整数溢出错误** |
| `mod`                 | 余数符号与 **被除数** 相同；除数为 0 → **除零错误**；余数不可表示 → **整数溢出错误**          |
| `abs`                 | 返回绝对值；`INT_MIN` 时 strict 报错                                                         |
| `neg`                 | 返回相反数；`INT_MIN` 时 strict 报错，wrap 回绕                                              |

**strict 溢出检测**（`div`/`mod`，有符号类型）：

1. 将操作数按 `<T>` 解码为 int64 有符号值
2. 除数为 0 → **除零错误**
3. `div`：计算向零截断商 \(q\)；若 \(q\) 不在 `<T>` 可表示范围内 → **整数溢出错误**
4. `mod`：计算余数 \(r\)（满足 \(|r| < |b|\) 且符号与被除数相同）；若 \(r\) 不在 `<T>` 可表示范围内 → **整数溢出错误**

**特殊情形**（`b ≠ 0`）：

| 表达式                   | 结果 | 说明                                                         |
| ------------------------ | ---- | ------------------------------------------------------------ |
| `div(T, INT_MIN(T), −1)` | —    | **整数溢出错误**（数学商 \(+2^{n-1}\) 不可在 `<T>` 中表示） |
| `mod(T, INT_MIN(T), −1)` | `0`  | 余数为 0，**不报错**                                         |
| `abs(T, INT_MIN(T))`     | —    | **整数溢出错误**                                             |
| `neg(T, INT_MIN(T))`     | —    | strict 时 **整数溢出错误**                                   |

**恒等式**（`b ≠ 0`，且 `div`/`mul`/`sub` 在 strict 模式下 **不溢出**）：

`mod(<T>, a, b) == sub(<T>, a, mul(<T>, div(<T>, a, b), b))`

> 当 `a = INT_MIN(T)` 且 `b = -1` 时，`div` 因商不可表示而报错，`mul` 亦会溢出，该恒等式不适用。`mod` 的余数仍为 0。无符号类型下该恒等式对任意非零除数 `b` 恒成立。

```text
var g: int32 = 7
var h: int32 = -3
var i: int32 = div(int32, g, h)    ; i = -2

var j: int32 = -7
var k: int32 = 3
var m: int32 = mod(int32, j, k)    ; m = -1

var n: int32 = -42
var o: int32 = abs(int32, n)       ; o = 42
```

### 5.3 整数无符号运算（`uint8`～`uint64`）

| 指令                  | 语义                                                |
| --------------------- | --------------------------------------------------- |
| `add` / `sub` / `mul` | 和 / 差 / 积；超范围模 2^n 回绕                     |
| `div`                 | 数学整数商；除数为 0 → **除零错误**                 |
| `mod`                 | 余数满足 `0 ≤ 余数 < 除数`；除数为 0 → **除零错误** |
| `abs`                 | 恒等返回                                            |
| `neg`                 | 返回 `0 - 操作数`，模 2^n 回绕                      |

无符号算术天然采用模 2^n 回绕，其位级结果与有符号 `wrap` 模式下的同宽算术一致。

```text
var a: uint8 = 200
var b: uint8 = 100
var c: uint8 = add(uint8, a, b)    ; c = 44

var h: uint8 = 5
var i: uint8 = 10
var j: uint8 = sub(uint8, h, i)    ; j = 251

var k: uint8 = 1u
var l: uint8 = neg(uint8, k)       ; l = 255
```

### 5.4 算术运算的扩展框架

当前版本仅实现了 **整数算术**。未来将逐步扩展：

| 运算类别     | 当前支持                                    | 未来扩展                                                    |
| ------------ | ------------------------------------------- | ----------------------------------------------------------- |
| **整数算术** | ✅ `add`/`sub`/`mul`/`div`/`mod`/`abs`/`neg` | 任意位宽整数                                                |
| **浮点算术** | —                                           | `fadd`/`fsub`/`fmul`/`fdiv`/`fneg`/`fabs`、`sqrt`、`sin` 等 |
| **位运算**   | —                                           | `and`/`or`/`xor`/`shl`/`shr`                                |
| **比较运算** | —                                           | `eq`/`ne`/`lt`/`le`/`gt`/`ge`（返回 `bool`）                |
| **逻辑运算** | —                                           | `not`/`and`/`or`（操作 `bool`）                             |

> 未来新增运算将复用相同的语法风格：`<op>(<类型> [, 模式], 操作数...)`。

## 6. 类型转换

### 6.1 `truncate` 模式详解

`cast` 使用 `truncate` 关键字表示按位截断/扩展/重解释。`wrap` 关键字 **不可用于 cast**。

```text
var big: int32 = 1000
var err: int8 = cast(int8, big)                  ; 转换溢出错误
var trunc: int8 = cast(int8, truncate, big)      ; trunc = -24

var n: int32 = sub(int32, 0, 1)                  ; n = -1
var bits: uint8 = cast(uint8, truncate, n)       ; bits = 255
```

### 6.2 整数严格转换规则（`strict`）

#### 加宽（目标位宽 > 源位宽）

| 源 → 目标       | 规则                              |
| --------------- | --------------------------------- |
| 有符号 → 有符号 | 符号扩展，数值不变                |
| 无符号 → 无符号 | 零扩展，数值不变                  |
| 有符号 → 无符号 | 源 ≥ 0 则转换；源 < 0 → 错误      |
| 无符号 → 有符号 | 源 ≤ 目标 max 则转换；否则 → 错误 |

#### 等宽（位宽相同，符号性不同）

| 源 → 目标       | 规则                              |
| --------------- | --------------------------------- |
| 有符号 → 无符号 | 源 ≥ 0 则转换；源 < 0 → 错误      |
| 无符号 → 有符号 | 源 ≤ 目标 max 则转换；否则 → 错误 |

#### 缩窄（目标位宽 < 源位宽）

| 源 → 目标       | 规则                                     |
| --------------- | ---------------------------------------- |
| 有符号 → 有符号 | 源在目标范围内则转换；否则 → 错误        |
| 无符号 → 无符号 | 截断低 n 位（mod 2^n），**不报错**       |
| 有符号 → 无符号 | 源 ≥ 0 且 ≤ 目标 max 则转换；否则 → 错误 |
| 无符号 → 有符号 | 源 ≤ 目标 max 则转换；否则 → 错误        |

> 无符号 → 无符号缩窄 **不做** 可表示性检查，等价于截断低 n 位。

#### 同类型

源类型与目标类型相同 → 恒等转换。

### 6.3 整数截断转换规则（`truncate`）

设源位宽 n、目标位宽 m；先将源操作数表示为 n 位整数 `bits`（`0 ≤ bits < 2^n`）。

1. **缩窄或等宽**（m ≤ n）：取 `bits mod 2^m`，按目标类型解释
2. **加宽**（m > n）：
   - 目标无符号，或源无符号：零扩展至 m 位
   - 源、目标均有符号且 `bits` 第 n−1 位为 1：符号扩展至 m 位
   - 其余加宽：零扩展至 m 位

| 场景                        | strict | truncate               |
| --------------------------- | ------ | ---------------------- |
| 有符号缩窄超范围            | 错误   | 截断低 m 位并重解释    |
| 有符号 → 无符号（源为负）   | 错误   | 重解释（如 −1 → 255）  |
| 无符号 → 有符号（源 > max） | 错误   | 重解释（如 200 → −56） |
| 无符号 → 无符号缩窄         | 截断   | 截断（相同）           |
| strict 下合法的加宽         | 扩展   | 相同结果               |

**`truncate` 结果的类型解释**：

`truncate` 的结果值为目标类型 `T` 的 n 位位模式按 `T` 的类型规则解释后的值。

```text
var neg: int32 = -1
var bits: uint8 = cast(uint8, truncate, neg)    ; bits = 255
var wrapped: uint8 = add(uint8, bits, 1)        ; wrapped = 0
```

truncate 加宽示例：

```text
var v8:  int8  = -1
var ext1: int16 = cast(int16, truncate, v8)    ; ext1 = -1（符号扩展）
var ext2: uint16 = cast(uint16, truncate, v8)  ; ext2 = 255（零扩展）

var u8:  uint8  = 200
var ext3: int16 = cast(int16, truncate, u8)    ; ext3 = 200（零扩展）
```

### 6.4 整数转换规则速查

**strict**：

| 源 ↓ / 目标 → | int（有符号）                    | uint（无符号）                |
| ------------- | -------------------------------- | ----------------------------- |
| **int**       | 范围内保留/符号扩展；超出 → 错误 | 非负且范围内；否则 → 错误     |
| **uint**      | ≤ 目标 max；否则 → 错误          | 同宽/缩窄：截断；加宽：零扩展 |

**truncate**：任意源 → 任意目标，按位模式算法处理，不报错。

### 6.5 类型转换的扩展框架

当前实现了 **整数 ↔ 整数** 的转换。未来将扩展：

| 转换场景    | 当前支持 | 说明                                       |
| ----------- | -------- | ------------------------------------------ |
| 整数 ↔ 整数 | ✅        | 任意位宽组合                               |
| 整数 ↔ 浮点 | —        | `cast(float32, int32_val)`                 |
| 浮点 ↔ 浮点 | —        | 精度转换（如 `float32` ↔ `float64`）       |
| 布尔 ↔ 整数 | —        | `cast(bool, int_val)`（0→false，非0→true） |
| 指针 ↔ 整数 | —        | 地址与整数互转                             |
| 复合类型    | —        | 结构体转换、数组重解释                     |

## 7. 标准 I/O

### 7.1 `write` — 不换行输出

**形式一：无格式输出**

| 项目       | 说明                                                        |
| ---------- | ----------------------------------------------------------- |
| 语法       | `write(int32, x)`、`write(uint8, 42u)`                      |
| 功能       | 将操作数的值按类型解释，以十进制文本写入 stdout，**不换行** |
| 操作数规则 | 变量（须已定义）或整数字面量                                |
| 类型约束   | 变量类型与 `type` 一致；字面量满足 §3.4 约束                |
| 输出格式   | 纯十进制，无前导零；有符号带 `-`；无符号无后缀              |

**形式二：格式化输出**

| 项目       | 说明                                            |
| ---------- | ----------------------------------------------- |
| 语法       | `write(int32, %d, x)`、`write(uint8, %x, 255u)` |
| 功能       | 按格式化符号输出操作数的值，**不换行**          |
| 操作数规则 | 变量或整数字面量；**恰好一个**操作数            |
| 类型约束   | 操作数类型与 `type` 一致，且与格式化符号兼容    |

**特别说明**：`int8` 和 `uint8` 按整数数字输出，而非 ASCII 字符。例如 `write(int8, 65)` 输出 `"65"`。

### 7.2 `writeln` — 换行输出

与 `write` 相同，但在输出末尾追加换行符 `\n`。

```text
var x: int32 = 10
write(int32, x)                    ; "10"
writeln(int32, %d, x)              ; "10\n"
```

### 7.3 `read` — 标准输入

| 项目     | 说明                                               |
| -------- | -------------------------------------------------- |
| 语法     | `read(int32, x)`、`read(uint8, count)`             |
| 功能     | 从 stdin 读取一个十进制整数，存入已定义变量        |
| 目标变量 | 必须已声明，且类型与 `type` 一致                   |
| 输入格式 | 十进制整数；`int*` 支持可选 `-` 前缀；跳过前导空白 |
| 错误处理 | 非法输入/数值超范围/非预期 EOF → **I/O 错误**      |

**输入规则**：
1. 跳过前导空白
2. `int*` 类型：可选 `-` 前缀
3. `uint*` 类型：**不接受** `-` 前缀
4. 读取连续十进制数字，至少一位
5. 数值超出范围 → I/O 错误
6. EOF 且无数字 → I/O 错误

### 7.4 格式化符号定义

| 符号 | 含义                    | 适用类型                       | 示例（值 42） |
| ---- | ----------------------- | ------------------------------ | ------------- |
| `%d` | 有符号十进制            | `int8`～`int64`                | `42`          |
| `%i` | 有符号十进制（同 `%d`） | `int8`～`int64`                | `42`          |
| `%u` | 无符号十进制            | `uint8`～`uint64`              | `42`          |
| `%x` | 十六进制（小写 a-f）    | 任一整数类型（按无符号位模式） | `2a`          |
| `%X` | 十六进制（大写 A-F）    | 任一整数类型（按无符号位模式） | `2A`          |
| `%o` | 八进制                  | 任一整数类型（按无符号位模式） | `52`          |
| `%b` | 二进制                  | 任一整数类型（按无符号位模式） | `101010`      |

**说明**：`%x`/`%X`/`%o`/`%b` 在有符号类型上输出其**无符号位模式**（二补码解释），如 `var x: int8 = -1; write(int8, %x, x)` 输出 `ff`。

### 7.5 类型兼容性

| 符号                      | 可接受操作数类型                      |
| ------------------------- | ------------------------------------- |
| `%d`                      | `int8`, `int16`, `int32`, `int64`     |
| `%i`                      | `int8`, `int16`, `int32`, `int64`     |
| `%u`                      | `uint8`, `uint16`, `uint32`, `uint64` |
| `%x` / `%X` / `%o` / `%b` | 任一整数类型                          |

**错误示例**：`write(int8, %u, x)` ❌（`%u` 要求无符号类型）

### 7.6 格式化输出扩展预留

> **扩展预留**：未来版本将支持更多格式化符号：
> - `%f` / `%F`：浮点数（十进制）
> - `%e` / `%E`：浮点数（科学计数法）
> - `%c`：字符
> - `%s`：字符串
> - `%p`：指针
>
> 格式化字符串中将支持宽度、精度等修饰符。

## 9. 错误与警告

遇到 **第一个** 错误即终止程序（fail-fast）。错误按发生阶段分为 **静态**（词法/语法/静态分析）与 **运行时** 两类。编译警告不影响程序执行。

### 9.1 静态错误（18 种）

| 错误类型         | 触发条件                                                     |
| ---------------- | ------------------------------------------------------------ |
| 词法错误         | 非法字符、整数字面量格式非法等                               |
| 语法错误         | token 序列不符合附录 A 的产生式                              |
| 未定义标识符错误 | 使用未 `var`/`let` 声明的标识符                              |
| 重复定义错误     | 同一作用域重复 `var`/`let` 同名标识符                        |
| 类型错误         | 运算或赋值时类型不一致                                       |
| 字面量范围错误   | 字面量数值超出上下文类型可表示范围                           |
| 字面量类型错误   | `u` 后缀字面量用于有符号类型上下文；或负号与 `u` 后缀组合    |
| 溢出模式错误     | `div`/`mod` 使用 `wrap`；`abs` 使用 `wrap`                   |
| 关键字错误       | `wrap` 用于 `cast`；`truncate` 用于算术运算；关键字用于错误上下文 |
| 常量赋值错误     | 对 `let` 定义的常量进行赋值                                  |
| 常量表达式错误   | `let` 的 RHS 不是编译期常量表达式                            |
| 格式字符串错误   | 格式符号不是 `%d`/`%i`/`%u`/`%x`/`%X`/`%o`/`%b` 之一         |
| 格式类型不匹配   | 操作数类型与格式化符号不兼容                                 |
| 操作数数量错误   | 格式化版本缺少操作数，或多于一个操作数                       |

### 9.2 运行时错误（4 种）

| 错误类型     | 触发条件                                                    |
| ------------ | ----------------------------------------------------------- |
| 除零错误     | `div`/`mod` 右操作数为 0                                    |
| 整数溢出错误 | 有符号类型 strict 模式下 `add`/`sub`/`mul`/`neg` 结果超范围 |
| 转换溢出错误 | `cast` strict 模式下结果无法在目标类型中表示                |
| I/O 错误     | `read` 读取失败                                             |

### 9.3 编译警告（1 种）

| 警告类型         | 触发条件                                                     |
| ---------------- | ------------------------------------------------------------ |
| 未初始化变量警告 | 读取尚未获得初值的变量。运行时值为 **未定义**（implementation-defined） |

## 附录 A：形式化语法（EBNF）

本附录为 TC 语言的 **权威语法定义**。语义规则以正文为准。

### A.1 符号约定

采用 **扩展巴科斯-瑙尔范式（EBNF）**：

| 元符号   | 含义              |
| -------- | ----------------- |
| `=`      | 产生式定义        |
| `\|`     | 择一              |
| `[ … ]`  | 可选（0 或 1 次） |
| `{ … }`  | 重复（0 或多次）  |
| `( … )`  | 分组              |
| `"…"`    | 终结符            |
| *斜体名* | 非终结符          |

### A.2 词法

```ebnf
/* ── 基本字符类 ── */

letter     = "A" … "Z" | "a" … "z" | "_" ;
digit      = "0" … "9" ;
hex_digit  = digit | "A" … "F" | "a" … "f" ;

/* ── 标识符与字面量 ── */

identifier = letter , { letter | digit | "_" } ;

integer_literal
           = [ "-" ] , (
               dec_literal [ "u" | "U" ]
             | hex_literal [ "u" | "U" ]
             | bin_literal [ "u" | "U" ]
             | oct_literal [ "u" | "U" ]
           ) ;

dec_literal = non_zero_digit , { digit | "_" } | "0" ;
hex_literal = ( "0x" | "0X" ) , hex_digit , { hex_digit | "_" } ;
bin_literal = ( "0b" | "0B" ) , ( "0" | "1" ) , { ( "0" | "1" ) | "_" } ;
oct_literal = ( "0o" | "0O" ) , ( "0" … "7" ) , { ( "0" … "7" ) | "_" } ;
non_zero_digit = "1" … "9" ;

/* 数字分隔符说明：下划线 "_" 仅用于可读性分隔，无语义。
   不允许连续两个下划线，也不允许下划线出现在字面量首尾。 */

/* ── 类型关键字 ── */

int_type   = "int8"   | "uint8"
           | "int16"  | "uint16"
           | "int32"  | "uint32"
           | "int64"  | "uint64" ;
/* 扩展预留：浮点类型 float32, float64；布尔 bool；复合类型 array, struct, ptr */

/* ── 运算与模式关键字 ── */

binary_op  = "add" | "sub" | "mul" | "div" | "mod" ;
/* 扩展预留：位运算 and, or, xor, shl, shr；比较 eq, ne, lt, le, gt, ge */

unary_op   = "abs" | "neg" ;
/* 扩展预留：浮点一元 fneg, fabs, sqrt；逻辑 not */

wrap_kw    = "wrap" ;
truncate_kw = "truncate" ;

/* ── 格式化符号 ── */

format_specifier
           = "%d" | "%i" | "%u" | "%x" | "%X" | "%o" | "%b" ;
/* 扩展预留：%f, %F, %e, %E, %c, %s, %p */

/* ── 注释 ── */

line_comment = ";" , { ? any character except newline ? } ;
```

### A.3 语法

```ebnf
/* ── 程序 ── */

program    = { ( statement , [ stmt_terminator ] , newline )
             | ws , [ line_comment ] , newline }
             [ ( statement , [ stmt_terminator ] )
             | ws , [ line_comment ] ] ;

statement  = variable_def
           | constant_def
           | assignment
           | write_stmt
           | writeln_stmt
           | read_stmt ;
/* 扩展预留：if_stmt, goto_stmt, loop_stmt, func_def, return_stmt */

/* ── 变量定义 ── */

variable_def = "var" , ws , identifier , ws , ":" , ws , int_type
             [ ws , "=" , ws , rhs ] ;

/* ── 常量定义 ── */

constant_def = "let" , ws , identifier , ws , ":" , ws , int_type , ws ,
               "=" , ws , const_rhs ;

/* ── 赋值语句 ── */

assignment = identifier , ws , "=" , ws , rhs ;

stmt_terminator
           = ";" , [ { ? any character except newline ? } ]
           | ws , line_comment ;

/* ── 右值表达式 ── */

rhs        = integer_literal
           | binary_arith_expr
           | unary_arith_expr
           | cast_expr ;

const_rhs  = integer_literal ;      /* 常量 RHS 仅允许字面量 */

/* ── 操作数 ── */

operand    = identifier | integer_literal ;

/* ── 双目算术表达式 ── */

binary_arith_expr
           = strict_binary_arith_expr
           | wrap_binary_arith_expr ;

strict_binary_arith_expr
           = binary_op , "(" , ws , int_type , ws , ","
             , ws , operand , ws , "," , ws , operand , ws , ")" ;

wrap_binary_arith_expr
           = binary_op , "(" , ws , int_type , ws , ","
             , ws , wrap_kw , ws , ","
             , ws , operand , ws , "," , ws , operand , ws , ")" ;

/* binary_op ∈ { add, sub, mul, div, mod }
   wrap 形式仅 add/sub/mul 合法；div/mod 使用则报错 */

/* ── 单目算术表达式 ── */

unary_arith_expr
           = strict_unary_arith_expr
           | wrap_unary_arith_expr ;

strict_unary_arith_expr
           = unary_op , "(" , ws , int_type , ws , ","
             , ws , operand , ws , ")" ;

wrap_unary_arith_expr
           = unary_op , "(" , ws , int_type , ws , ","
             , ws , wrap_kw , ws , ","
             , ws , operand , ws , ")" ;

/* unary_op ∈ { abs, neg }
   wrap 形式仅 neg 合法；abs 使用 wrap 则报错 */

/* ── 类型转换表达式 ── */

cast_expr  = strict_cast_expr | truncate_cast_expr ;

strict_cast_expr
           = "cast" , "(" , ws , int_type , ws , ","
             , ws , identifier , ws , ")" ;

truncate_cast_expr
           = "cast" , "(" , ws , int_type , ws , ","
             , ws , truncate_kw , ws , ","
             , ws , identifier , ws , ")" ;

/* cast 源操作数须为变量，不可为字面量或嵌套表达式 */

/* ── I/O 语句 ── */

write_stmt = "write" , "(" , ws , int_type , ws , ","
             , ws , operand , ws , ")"
           | "write" , "(" , ws , int_type , ws , ","
             , ws , format_specifier , ws , ","
             , ws , operand , ws , ")" ;

writeln_stmt = "writeln" , "(" , ws , int_type , ws , ","
               , ws , operand , ws , ")"
             | "writeln" , "(" , ws , int_type , ws , ","
               , ws , format_specifier , ws , ","
               , ws , operand , ws , ")" ;

read_stmt  = "read" , "(" , ws , int_type , ws , ","
             , ws , identifier , ws , ")" ;

/* ── 空白 ── */

ws         = { " " | "\t" } ;
newline    = "\n" | "\r\n" | "\r" ;
```

## 附录 B：与 C 语言整数语义对照

| 类型        | TC 类型  | C 语言等价 |
| ----------- | -------- | ---------- |
| 8 位有符号  | `int8`   | `int8_t`   |
| 8 位无符号  | `uint8`  | `uint8_t`  |
| 16 位有符号 | `int16`  | `int16_t`  |
| 16 位无符号 | `uint16` | `uint16_t` |
| 32 位有符号 | `int32`  | `int32_t`  |
| 32 位无符号 | `uint32` | `uint32_t` |
| 64 位有符号 | `int64`  | `int64_t`  |
| 64 位无符号 | `uint64` | `uint64_t` |

| 运算           | TC（新）                                | C 等价                       |
| -------------- | --------------------------------------- | ---------------------------- |
| 有符号字面量   | `42`                                    | `42`                         |
| 无符号字面量   | `42u`                                   | `42u`                        |
| 加             | `add(int32, a, b)`                      | `(int32_t)a + (int32_t)b`    |
| 加（回绕）     | `add(int32, wrap, a, b)`                | 同宽无符号运算后 reinterpret |
| 减 / 乘        | `sub` / `mul`                           | 对应 `-` / `*`               |
| 整除 / 求余    | `div` / `mod`                           | `/` / `%`（`INT_MIN / −1` 在 C 为 UB） |
| `INT_MIN / −1` | `div` → **整数溢出错误**；`mod` → `0`   | C 为 **UB**（Java/C# 定义 `div` 为 `INT_MIN`） |
| 取绝对值       | `abs(int32, a)`                         | `llabs(a)`                   |
| 取负数         | `neg(int32, a)`                         | `-a`                         |
| 取负数（回绕） | `neg(int32, wrap, a)`                   | 同宽无符号运算后 reinterpret |

| 转换     | TC                        | C                                 |
| -------- | ------------------------- | --------------------------------- |
| strict   | `cast(int8, a)`           | `(int8_t)a`（不可表示时 TC 报错） |
| truncate | `cast(int8, truncate, a)` | `(int8_t)a`（按位截断）           |

| I/O          | TC                     | C 等价             |
| ------------ | ---------------------- | ------------------ |
| 无格式输出   | `write(int32, x)`      | `printf("%d", x)`  |
| 有符号十进制 | `write(int32, %d, x)`  | `printf("%d", x)`  |
| 无符号十进制 | `write(uint32, %u, x)` | `printf("%u", x)`  |
| 十六进制小写 | `write(uint32, %x, x)` | `printf("%x", x)`  |
| 十六进制大写 | `write(uint32, %X, x)` | `printf("%X", x)`  |
| 八进制       | `write(uint32, %o, x)` | `printf("%o", x)`  |
| 二进制       | `write(uint32, %b, x)` | 无标准等价（扩展） |

**主要差异**：
- TC 有符号 strict 溢出报错（C 为 UB）
- TC `div(INT_MIN, −1)` 报整数溢出错误（C 为 UB；Java/C# 将 `div` 定义为 `INT_MIN`）
- TC `cast` strict 对不可表示转换报错（C 为实现定义/UB）
- TC 未初始化变量读取为编译警告 + 实现定义值（C 为 UB）
- TC 二进制 `%b` 为扩展格式
