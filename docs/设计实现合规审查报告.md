## 模块合规摘要

以下按编译流水线顺序归纳已验证的设计要点；细项编号与对照源码一一对应，此处仅保留结论性描述。

### 类型系统（33）

- `TcType` 8 种定宽整数 + `bool` + 2 种浮点；`TcWrapMode` / `TcTruncateMode` / 算术·比较·逻辑·格式·符号枚举完整
- **`FloatType` 2 种浮点**（`TC_FLOAT32`/`TC_FLOAT64`）；`FloatMode`（`TC_FP_STRICT`/`TC_FP_IEEE`/`TC_FP_WRAP`）
- `TcValue { type, bits }` 统一容器；`TcLiteral` 含 `magnitude/negative/unsigned_suffix/is_bool` **`is_float`**，`is_bool` 与整数 `0/1` 可区分
- `tc_type_is_integer()` 显式范围 `TC_INT8..TC_UINT64`，`TC_BOOL` 注释澄清非整数类别；**`tc_type_is_float()`** 新增
- `TC_STMT_IF` + `TcIfStmt { condition, then_body, else_body }` AST 结构
- **35 种 `TcErrorKind`**（含 `TC_ERR_OUT_OF_MEMORY`、7 种 if/缩进相关、**5 种浮点新增**）；`TcSymbol.scope_end_stmt_index` 块可见上界

### 词法（22）

- 标识符 ASCII；四进制整数字面量（十/十六/二/八）、`_` 分隔符、`u` 后缀与范围/前导零校验
- **浮点字面量**：十进制浮点、科学计数法、`f`/`F` 后缀、`inf`/`-inf`/`nan` 特殊值；`float32` 范围溢出校验
- `true`/`false` → `TC_TOK_BOOL_LIT`；`;` 行注释；非法 `%` 格式报错
- `if`/`then`/`else`/`end` → `TC_TOK_IF`/`THEN`/`ELSE`/`END`；调试名映射完整

### 语法（47）

- 语句分派：`var`/`let`/I/O/赋值/`if`；可选 `;`
- **16 种 `TcRhsKind`** 解析分支完整（含 `BITWISE_BIN/UN`、`SHIFT`、**`FLOAT_ARITH`/`FLOAT_UNARY`/`FLOAT_COMPARE`/`FLOAT_CAST`**）
- 关键字约束：`wrap`/`truncate` 禁用于非法上下文；**`ieee` 仅浮点上下文**；cast 源须变量；let 必有 RHS；按位/移位禁模式关键字；let 中 `shl wrap` 在 Parser 拒绝
- `tc_parse_if_stmt`：多行缩进状态机（R1–R6）；`then` 行末、`else`/`end` 单独成行且与 `if` 对齐；嵌套 if 递归解析
- `tc_statement_free` 递归释放 `then_body`/`else_body`；`libtc` 入口 `tc_parse_source_to_program` 两遍行扫描

### 符号表（10）

- `TcScope` 栈 + `scope_level`；`push_scope`/`pop_scope`/`current_scope`
- `find_in_scope` 内层优先 shadowing；`find_in_current_scope` 重复定义检测
- then/else **各自** push/pop，允许同名局部变量；Pass1 全局 slot 预分配
- `scope_end_stmt_index` 标记块内符号可见上界；`pop_last` REPL 回滚兼容

### 静态分析（49）

- Pass1 符号收集与 Pass2 源序可见性；重复/前向引用/自引用检测；DFS `stmt_index` 扁平序号
- 字面量种类与范围；I/O 格式符与操作数数量；未初始化变量警告（含 `read` 初始化、`last_init_stmt_index`）
- **逻辑短路**：`and`/`or` 字面量 lhs 抑制 rhs 未初始化警告；非字面量不抑制
- **整数按位无短路**：`BITWISE_BIN/UN` 两侧均检查；`shr` + `wrap` → 关键字错误
- **if 条件**：`tc_check_rhs` 要求结果类型 `bool` → `TC_ERR_CONDITION_TYPE`
- **块作用域**：then/else 递归 Pass1/Pass2；跨块引用 → `TC_ERR_UNDEFINED_VARIABLE`/`TC_ERR_CROSS_BLOCK_REFERENCE`
- **浮点（v0.0.25）**：`FLOAT_ARITH`/`FLOAT_UNARY`/`FLOAT_COMPARE`/`FLOAT_CAST` 类型检查；`mod` 禁浮点 → `TypeMismatch`；`ieee` 禁整数 → `ModeMismatch`；`wrap` 仅浮点算术/单目

### 常量求值（17）

- let RHS 委托 `tc_exec_*`（strict）；禁 `wrap`/`truncate`、禁 var 引用、循环依赖与缩窄 cast 检测
- 位运算/移位编译期求值；let 逻辑短路（按 `bits`）；let 禁 `shl wrap`
- if 块内 let 共享块级可见性，编译期求值路径不变
- **浮点常量（v0.0.25）**：`tc_eval_const_rhs` 新增浮点算术/比较/cast 编译期求值分支；以 `float64` 精度计算；禁 `ieee`/`wrap`；溢出/除零/无效操作 → 对应常量错误

### 语义（40）

- 双目/单目算术：strict 溢出检测、wrap 二补数、除零与 `INT_MIN/-1` 特例、64 位乘法分块
- 比较返回 bool；逻辑短路求值；cast 加宽/缩窄/truncate 与 `bool`↔整数规则
- 位运算 and/or/xor/not 无溢出；移位 shl strict/wrap、shr 算术/逻辑、k 不掩码
- **浮点语义（v0.0.25）**：`exec_fp_arith`（strict/ieee/wrap 3 模式）、`exec_fp_unary`（abs/neg 浮点）、`exec_fp_compare`（NaN 规则、ieee 模式）、`exec_fp_cast`（strict 值检查、truncate 位重解释）

### 执行器（22）

- 槽位 = 符号表 count，毒化 `0xFE`；VarDef/ConstDef/Assign/I/O/`if` 分派
- 逻辑短路在 `tc_eval_rhs`；整数按位无短路；let 常量读 `const_value` 不求值
- `TC_STMT_IF`：条件 `tc_eval_rhs(TC_BOOL)` → 递归执行 then/else；未执行分支跳过 `stmt_index`
- 符号查找尊重 `scope_end_stmt_index`
- **浮点执行（v0.0.25）**：`tc_eval_rhs` 新增 `FLOAT_ARITH`/`FLOAT_UNARY`/`FLOAT_COMPARE`/`FLOAT_CAST` 分发 → 对应 `exec_fp_*` 函数

### I/O（18）

- 无格式与 `%d/%i/%u/%x/%X/%o/%b/%t` 输出；`write`/`writeln`；int8/uint8 走整数路径
- `read` 有/无符号与 bool（小写敏感）解析及范围校验
- **浮点 I/O（v0.0.25）**：新增 `%f`/`%e`/`%E`/`%g`/`%G` 格式符；`tc_io_write_value`/`tc_io_read_value` 支持 `float32`/`float64`

### AOT（21）

- 语义与 I/O 委托 `tc_semantics` / `tc_io`；**16 种 RHS codegen**（含 4 种浮点 RHS）；let 编译期折叠
- shim 覆盖 `tc_aot_bitwise_*`、`tc_aot_shift`、**`tc_aot_fp_arith`/`tc_aot_fp_unary`/`tc_aot_fp_compare`/`tc_aot_fp_cast`**
- `TC_STMT_IF` → C `if (_cond) { ... } else { ... }`；递归 `tc_aot_emit_statement_impl`；块内符号 `scope_end_stmt_index` 查找

### 错误诊断（16）

- **35 种 `TcErrorKind`**（含 `TC_ERR_OUT_OF_MEMORY`、7 种 if/缩进、**5 种浮点：`FLOAT_OVERFLOW`/`FLOAT_UNDERFLOW`/`FLOAT_INVALID`/`FLOAT_CAST_OVERFLOW`/`MODE_MISMATCH**）；1 种 `TC_WARN_UNINITIALIZED_VARIABLE`
- `tc_error_kind_name()` 打印名与标准说明书 §11.4、VM 详设 §11.3 一致
- `TcDiagnostic` 含 snippet/caret；fail-fast 单槽

### libtc（8）

- `tc_compile_source` / `tc_compile_file` / `tc_run_typed` 签名与 fail-fast 契约
- Parse 失败不改 `out`；`TC_BENCH=1` 三阶段计时
- `tc_parse_source_to_program` 多行缩进感知解析（文件模式）

### REPL（2）
